# 道具图像生成 · 约束手册

---

## 一、道具设计原则

1. **功能可读** — 道具用途一目了然，造型服务于功能；结构逻辑自洽（符合真实装配/力学逻辑），禁止凭空悬浮件与无意义装饰件堆砌，可读性优先于装饰密度
2. **质感极致** — 材质纹理必须清晰可辨（金属/玉石/木/布/纸），PBR物理材质多通道表现（基色/粗糙度/金属度/法线分层），材质微结构可见，细节密度对标影视级3D国漫资产，禁止塑料玩具感与平涂无细节
3. **年代一致** — 所有道具必须符合古风世界观，形制/纹样/工艺考据对齐古风体系（剑格剑首剑鞘装具、谷纹螭纹玉饰、博山炉青瓷炉等），禁止现代元素（螺丝钉/拉链/塑胶/霓虹/电子元件等一切现代工业痕迹）
4. **尺度明确** — 通过画面内道具与同套件的相对比例、或道具与格框的占比关系暗示真实尺寸（禁以人体/手部作参照，画面禁文字标注，见 X7/X3/X8）
5. **纯道具独立展示** — 画面中只能出现道具本身，严禁出现任何人物、手部、肢体；道具不可处于被持有/佩戴/握持/使用中的状态，不可出现暗示人物存在的元素（手持痕迹、佩戴视角、使用姿态），必须以静物陈列方式独立呈现（平置/架放/自然悬浮皆可——悬浮按法宝设定含灵力悬浮逻辑，禁无逻辑物理漂浮；须稳定不飘浮、无人体接触件）

## 三、多角度设定图规范

### 视图定义

| 位置 | 视图 | 角度 | 要求 | 提示词 |
|---|---|---|---|---|
| 左上 | 正面图 | 正面 0° | 道具完整正面形态，左右对称件成对呈现（耳饰成对/格首居中/纹样居中对称），轮廓边缘清晰无透视倾斜 | front view、symmetrical front |
| 右上 | 侧面图 | 侧面 90° | 厚度/纵深/轮廓/结构清晰（鞘厚、杯把与盖钮朝向、柄茎与格首的层次关系），纯侧视无旋转错位 | side view、profile、thickness clear |
| 左下 | 背面图 | 背面 180° | 道具背部结构/装饰清晰（背部铭文/扣件/系绳/纹样连续性完整呈现） | back view、rear detail |
| 右下 | 细节特写 | 局部放大 | 材质纹理/工艺细节局部放大，给出具体看点（刃口开刃线、錾刻纹样、包浆磨痕、织纹、釉下刻花等），占格主体更大 | detail closeup、macro texture、edge detail |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 同一画面四宫格（2×2），上下左右四视角等距排布，格距均匀、无元素跨格、无重叠 |
| 背景 | 素灰纯色 #B8B8B8，四格底色完全一致 |
| 光线 | HDR柔和环境光 + 前方主光 + 双侧补光，光向四格一致，无硬阴影、无镜像高光错乱 |
| 比例 | 每格道具占格内主体 70%+，细节特写格占比可提至 80%+ |
| 投影 | 允许自然地面微投影（软接触影），禁止镜面反射地面与复杂桌面场景 |
| 一致性 | 四格为同一道具/同一材质/同一做旧状态/同一尺度，仅视角不同（禁格间道具换件、变色、做旧漂移） |
| 画面比例 | 建议 1:1 |

## 六、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须指定「素灰纯色背景」 |
| R2 | 必须明确道具材质与工艺，按「主体形制+材质+工艺/装饰+做旧状态」四要素落词，禁只写空泛道具品名 |
| R3 | 道具造型必须符合古风世界观，形制/纹样/工艺对齐古风体系（冷兵器/首饰/器物/信物各循其谱） |
| R4 | 必须声明「PBR材质渲染 + 材质纹理超清晰」，材质微结构可见，细节密度对标影视级3D国漫资产 |
| R5 | 必须输出四宫格设定图（正面+侧面+背面+细节特写），四格同一道具/材质/做旧状态，仅视角不同 |
| R6 | 做旧必须克制且符合使用逻辑（磨损/包浆集中于棱角与接触处），禁全件糊脏、禁噪点淹没材质辨识 |
| R7 | 细节特写格必须给出局部看点（刃口/纹样/包浆/织纹/釉下刻花等具体部位），不得空置或用广角凑数 |
| R8 | 输出前复核「纯道具静物」五项：无人物/无手部肢体/无佩戴使用态/无文字/无现代工业痕迹 |
| R9 | 必须携带统一负向词块与器物向锁质英文锚词（纯道具静物按全局前缀 X11「无人/纯器物场景豁免」条落场景档子集、清单以《art_scene》X15 为唯一权威；输出时成块附带、禁省略禁截断） |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 复杂场景背景 |
| X2 | 道具与人物同画面（本环节为纯道具图） |
| X3 | 出现任何人物形象，包括全身、半身、局部（手、手指、手臂等肢体） |
| X4 | 道具处于被持有、握持、佩戴、使用中的状态 |
| X5 | 出现暗示人物存在的元素（如手持痕迹、佩戴视角、使用姿态） |
| X6 | 现代工业痕迹混入古风道具（螺丝钉/拉链/塑胶件/霓虹/电子元件/现代字体等） |
