## 四、A/B 双面容基因档（通用模型可读 · 跨模型通用）

> 本章是「面容 · 建模 · 场景 · 道具」共用的**风格基因档**，目标只有一个：让任意主流 AI 模型（中文对齐型 / 英文对齐型 / 多模态对话型 / 本地工程流）都能听懂看懂，并稳定产出同一种审美取向——而不是复刻某张参考图。设计依据（联网核验）：①风格化与写实是一条连续光谱而非二元对立（行业通行对照：风格化＝夸张比例 + 简化纹理 + 主动打光，写实＝解剖准确 + PBR 物理光照 + 毛孔皱纹级细节，两端各有恐怖谷与代入感代价）；②纯文本出图身份漂移的根因是"每一个未定义的属性都是一次抛硬币"，可控变量是可测量、解剖学具体的结构词，而非"美/帅/精致"类主观词；③跨场景一致性的工程做法是"身份锚点 + 角色设定表 + 模块化提示词 + 负向词保护面部件"，设定表要素含脸与发、服装规则、表情风格、动作风格、不可改变项、允许变化项；④东方重彩三维化的工业做法是矿物色板分区配色 + PBR 分层材质表现颜料厚度与色阶 + 弱化写实强明暗改柔和漫射光 + 平远构图与晕染层次组织光影。本章据此把"那张脸"拆成可迁移的基因，**参考图只作观感标尺、其画面内容严禁写入提示词**。

### 4.0 定义、边界与三原则

- **风格基因** — 指跨题材可迁移的那部分风格信息：骨相结构、风格化程度、材质语言、光影语言、色彩组织方式、造型语言。基因与"剧情锚点"分离：剧情锚点（人物身份、服饰形制、场景类型、道具设定）由角色卡/场景卡/道具卡承担，基因由本章承担，两者在提示词中分块共存、互不顶替。
- **不写死参考图** — 参考图中的具体人物身份、服饰形制、建筑类型、事件场景，以及一次性配色叙事组合（如"某色配某纹""某色配某绣"这类只属于那张图的一体化搭配）一律不入基因词块；出现作品名/角色名/厂牌名/引擎名即判写死。
- **档位只管处理方式、不管情绪调性** — A/B 决定"结构与材质怎么处理、光影怎么组织"，**不决定**"这场戏是明是暗、是冷是暖"。明暗冷暖一律由情绪色盘与 A-I 光影方案管辖：A 型可演夜戏与暗场、B 型可演日戏与亮场；以风格档名义绕过色盘纪律即判越权。
- **通用模型可读三原则** — ①**结构词优先**：只用可测量、解剖学与工程学具体的词（脸型/眼型/鼻型/下颌线/粗糙度档/色温档），禁"精致/高级/氛围感/唯美"等无法解析的主观词充当风格指令；②**中英双写**：同一语义同时给中文结构词与英文结构词，使中文对齐型与英文对齐型模型皆可命中，两语不得互相矛盾；③**禁专有名词**：不出现作品名、角色名、厂牌名、引擎名与自造黑话，一律改以行业通用术语描述（半写实CG / 风格化比例 / 次表面散射 / 平远构图 / 分层粒子等）。

### 4.4 风格档锁定与四环继承

- **建卡即锁档** — 角色卡/场景卡/道具卡在首版产出一经定档（A 或 B），写入卡片元数据，全剧不再改档；改档＝重出该卡全量资产。
- **同片可共存、同角色不混档** — A、B 两档可在同一部片中并存（如人族修行主线走 B、神族神战副线走 A），但同一角色/场景/道具不得跨档漂移；双题材并存的片按**主线题材**锁全片基调（次要题材线仅该线角色与其专属场景/道具可另档），并在线别元数据显式标注题材归属以防跨线串档（对齐本节「定档判据」先判作品级题材的判定顺序）。
- **四环逐级继承** — 角色 → 角色衍生（妆容服化） → 分镜（逐镜画面词） → 分镜视频（风格标签），四环必须继承同一档位代号，任一环缺失档位代号即判不合格。
- **定档判据（先判据、后锁档）** — 档位不是默认值，须按下列线索**加权判定**，判据命中结果与命中项一并写入卡片元数据（留痕可复核）。判定顺序为「**先判作品级题材、再判角色级线索**」：题材映射为首要线索、其命中票**按两票计**（其余线索各一票），因为题材决定了全片的建模与特效基调——**人族修仙/玄幻/奇幻题材落 B 型**（风格化美型建模，行业代表为《完美世界》式建模与华丽特效、《斗罗大陆》《吞噬星空》式美型建模），**神族神话题材落 A 型**（写实向神性造像，行业代表为追光动画《新神榜》系列式神话题材写实向 CG；两档观感标尺与"作品名严禁入提示词"的纪律见 §4.1 表后说明）；题材线索与角色级线索冲突时**以题材线索为准**（如神族题材中的凡人侍从随题材落 A、人族修仙题材中的伪神反派随题材落 B），防同一部片内因个别角色而整体基调摇摆。判定口径：A 权重多者落 A、B 权重多者落 B；权重持平或无线索可依 → 先看题材线索，题材亦不明 → 兜底 A 型，并在卡片标注「档位待人工复核」。**禁以单一角色标签词直接定档**（如仅凭某角色台词出现"神族"三字落 A）：题材判定须基于作品级题材定位、不得因个别字样改判题材；族属常以未直呼其名的方式书写（"承血者/旧朝余脉/天枢阁/堕神残裔"等），必须按语义判、不得按字面判。

|---|---|---|

- **档位来源与继承链（下级不自立档，全局唯一源头是角色卡）** — 场景卡/道具卡与三本衍生卡均不自立档位，一律锚定继承，并在元数据显式标注来源：
  - 归属明确（某角色的居所、法器、本命物、随身物、衣饰）→ 继承该**角色卡**档位，来源标注「继承自 {角色名} 卡」。
  - 族属/门派/势力共用（神殿、宗祠、族徽、山门、宗门建筑群、制式法宝）→ 继承该族系/门派**首例卡（首座卡）**档位，来源标注「继承自 {族系/门派} 首例卡」，防族相漂移。
  - 纯功能性中性场景/道具（荒野、客栈、市集、通用器皿，不含族属设定）→ 取同镜出场角色档位；同镜无角色出场 → 兜底 A 型。
  - 分镜与分镜视频不自行定档，逐镜继承该镜出场角色卡与场景卡档位；同镜多角色跨档时，**画面风格以该镜主体角色档位为准，其余角色保留各自面容基因**（面容各归其卡、画面风格归主体），不得因并置而互相污染。
  - 执行顺序锁定为「**先定档 → 再落词块 → 再出图**」；出图前须先产出「档位与来源清单」（卡名 → 档位 → 来源），清单缺来源项即判不合格、先补齐再出图。此项落位纪律的判定，见 §4.5 R13/R14 与 X16/X17。
- **本档不改既有纪律** — 本章不替代、不放宽任何既有条款：色盘 C1-C15 与情绪色盘、A-I 光影方案、R/X 全表、统一负向词块与锁质/锁神锚词一律继续生效；本章只在"结构处理方式与材质光影组织方式"这一层追加档位变量。

### 4.6 负向词与锚词的投喂预算纪律（跨平台）

- **总量与结构分层** — 统一负向词块按三层组织投喂，禁"一句不留全表倾倒"：**保底层（必投，约 6-8 个）**只放结构失败类词（塑料感/建模粗糙/低质量/模糊/柔焦/2D 平涂与赛璐璐着色——对应本表词块中的 plastic look, rough modeling, low quality, blurry, soft focus, 2D anime flat shading, cel shading）；**域层（按题材投）**放该域高发误渲对象（人物域、器物域的 neon glow on seal / mirror specular on seal / flat black cloth slab 等）；**增补层（按实测投）**只放单卡/单镜实测出的特有缺陷。负面约束的有效性随条数增长递减，过量会从"排除缺陷"翻转为"过度纠正、画面发板"——把有限的约束额度留给最致命的几项，比铺满全表更有效。
- **正负配比** — 单条提示词内正向结构词与负向词的数量比宜落在 3:1-4:1（本体系推荐值、非平台硬限）；负向词明显多于正向结构词时，先补正向结构词，而不是继续加负向词。
- **字符预算** — 遵守平台配额（如可灵系正负各 2500 字符、独立配额）。**裁剪顺序设计成"从尾部裁"**：保底层置于词块最前、域层次之、增补层最后；超预算时先裁增补层、再裁域层，**保底层不动**。
- **与 X11 的关系（不冲突）** — X11「整块附带、禁省略禁截断」约束的是**投喂动作**（成块搬运、不得手改词序与语义）；本节约束的是**总量预算与分层裁剪优先级**（裁剪有先后、不是随手删）。两者叠加执行：整块取用 → 按层落位 → 超限时按优先级裁尾。
- **锚词不参与裁剪** — 锁质锚词与锁神锚词属正向必投项，不算负向预算，禁因压缩长度而删锚词。

### 4.7 锁定项与可变量分栏（身份—服化—镜头—状态 四层可变性）

本表把体系内既有的"不漂移"要求显式分层，并**首次定义每层允许变化的量**——只锁不松会让分镜拒绝换姿态，只松不锁会跨镜换脸，两者都是不合格。（与 X14/X15 不冲突：本表只管"哪一层能变"，不管画面调性。）

| 层 | 锁定项（零变体，跨镜跨卡逐字复用） | 允许变化项（每镜/每卡可变，但须显式写出） |
|---|---|---|
| L-身份层（角色卡） | 骨相与三庭五眼、脸型轮廓、五官形制与比例、眼型与瞳色、发际线与发色发质、身形与头身比、可校验锚点（印记/旧疤/瞳色异象/不对称发式）、年龄呈现档 | 本层全锁，无允许变化项 |
| L-服化层（角色衍生） | 面容基因与全部身份锚点（禁改） | 妆容、发型束式、服制、配饰、戏用状态（损伤/染血/湿身/蒙尘）、季节与场合变体 |
| L-镜头层（分镜） | 身份层与服化层已锁定项、档位代号 | 景别、机位角度、视高、透视、构图、镜头运动、焦点位置与景深 |
| L-状态层（分镜/分镜视频） | 身份层 | 情绪、姿态、动作、视线方向、口型与呼吸、环境氛围、光照方案、色盘归属 |

- **双向纪律** — 锁定项零变体；可变量**逐镜必须变**——连续两镜复制同一景别+同一机位+同一姿态＝复制粘贴，不算分镜（对齐《分镜表叙事手法》重复镜判定）。同时禁以"追求变化"为由改动锁定项（那是换脸，非变化）。
- **未定义即掷骰** — 凡未列入本表锁定项列的属性，一律视为可变量；可变量若在该镜提示词中未显式给出，则由模型自由发挥，等同未定义。此条与 §4.0「每一个未定义的属性都是一次抛硬币」互为表里。

## 五、未列元素推演条（Fallback · 全体系通用）

> **立据与适用（2026-09 联网核验）** — 本体系的知识结构是**"闭集编号 ＋ 开放属性"**：色盘 C1-C15、全局 R1-R14/X1-X17、A-I 光影方案、锁质/锁神锚词表、平台时长与帧数额度为**闭集**（只减不增），而剧本/设定中出现的元素是**开放集**——必会出现手册未列之物。故设本节：**未列元素一律不许新增编号，须按下方四步推演落到既有编号上，并登记推演来源**。本节**不新增全局 R/X 编号**；违反本节按既有分项归责（推演不登记＝对齐 X16「判据未留痕」；新造色名或自定义 hex＝X2；越过锁定项＝§4.7 双向纪律）。本节随本前缀注入即自动生效，各承载手册无需重写、按名引用即可。
