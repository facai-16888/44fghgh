# 场景衍生资产生成 · 约束手册

---

## 一、衍生原则

1. **空间一致** — 建筑结构/布局/材质在所有变体中保持一致：基于参考图/img2img 同源衍生（固定seed、参考图锚定），L1 不变特征层全程锁定（L1=本手册场景结构锚定记号：空间结构+布局+材质基底+主色，与全局美学 L1 色域硬约束、人物衍生 L1 妆容层、道具衍生 L1 造型锚定层记号无关）——基础空间结构（柱网开间、屋脊走向、飞檐斗拱）、布局（门/窗/主要通道/出入口的位置关系）、材质基底与主色（对齐全局色盘 C1-C15）；以「场景识别特征」作锚点元素（青灰砖墙/木横梁/格扇窗位/门头雕花等），无论景别角度怎么变都不许消失；禁变体顺手改格局、改材质、移动门窗位
2. **景别驱动** — 同一场景通过不同景别展示不同叙事功能：大全景定位世界与地理关系（establishing shot）、全景展示空间结构、中景聚焦功能区、近景收敛材质与氛围道具、特写锁定关键细节；景别词前置且单条只用一个景别（禁一条提示词混用多景别导致模型折中产出平庸构图）；宏观景别写体量/布局/光线氛围（不写机理细节防噪点），微观景别才写材质纹理反光
3. **时段切换** — 同一空间在不同时间段呈现不同光影氛围：天空色调、色温、阴影长度、灯烛亮灭按物理与古风生活逻辑切换（昼=天光 5200-5600K 阴影短；黄昏=低角暖金 golden hour 长影（2000-3500K）天空金靛渐变；月夜=6500-8000K 冷蓝长清辉；烛火/灯笼=3000-3800K 暖黄为唯一人工点光源），灯具亮灭符合古代时序（入夜方点灯），禁昼夜光混打、禁白天满堂灯火
4. **天候变化** — 同一空间在不同天气下呈现不同情绪：晴天清朗锐利、阴天均匀压抑（overcast 无硬影）、薄雾朦胧虚远、细雨凄清湿润、飞雪静谧素白；天候须与季节气候自洽（夏无飞雪、冬无雷暴，对齐本手册 X2）；材质表面随天候响应（雨=湿反光积水、雪=覆盖挂霜、雾=远物模糊化入雾幕），禁只加粒子不改材质表面
5. **3D为锚** — 所有变体必须保持 3D 半写实国漫渲染质感（3D写实渲染管线，风格基线同全局前缀），拒绝 2D 平面贴图感与廉价 CG 动画塑料感；保留体积光（光柱须借尘埃/云雾/灵气光尘介质方可可视）、环境光遮蔽、景深虚化、HDR

## 二、景别变体

### 景别定义

| 景别 | 范围 | 叙事功能 | 提示词 |
|---|---|---|---|
| 大全景 | 场景全貌 + 周围环境（山势水系/聚落与环境关系） | 建立空间感、定位（establishing shot 定场，地理关系与尺度感优先） | extreme wide shot、establishing shot、大全景、16-24mm 广角 |
| 全景 | 场景完整呈现（主体建筑与环境边界清晰） | 展示空间结构与建筑体量 | wide shot、全景、24mm 广角 |
| 中景 | 场景局部区域（一进院落/一座殿/一条街段） | 聚焦功能区、空间定向 | medium shot、中景 |
| 近景 | 场景细部（檐下斗拱、格扇窗、门头、墙面+氛围道具） | 材质/氛围道具特写，写材质纹理反光（此层级起进入微观写法） | close shot、近景、50mm |
| 特写 | 极局部细节（木纹年轮、砖缝苔痕、瓦当雕纹、门钹铜环） | 材质纹理/关键道具极近呈现，空间压缩感强 | extreme closeup、特写、100mm 微距、shallow depth of field |

### 景别衍生规范

| 从基准图衍生 | 保持不变 | 允许变化 |
|---|---|---|
| 大全景 → 全景 | 建筑外观、整体布局、天光方向与季节（同一地形关系、同一主朝向） | 视角收窄（同向拉近、非旋转换向）、前景增加框景元素；禁微缩细节堆噪 |
| 全景 → 中景 | 材质、色调、光线（光向不变、季节天候不变） | 裁切聚焦（画面缩到参考图局部）、景深变化；禁顺手改建筑细部（格扇数/瓦垄行数/开间漂移） |
| 中景 → 近景 | 材质、色调（同源构件：同门头同檐角同段墙） | 景深浅、背景虚化；禁近景中出现参考图中不存在的构件与陈设（凭空新增楼阁/器物） |
| 近景 → 特写 | 材质纹理（同一块木面/同一片砖墙，纹理放大不换材质） | 极浅景深、微距感（macro），细节密度提升；禁特写对象「换皮」与参考图断连 |

## 三、时段变体

### 时段定义

| 时段 | 视觉特征 | 提示词 |
|---|---|---|
| 清晨 | 薄雾柔光、色调偏冷暖交织：日出低角暖光（3000-4000K 向）穿雾漫射，露水湿润反光，天空由冷转暖渐变，影子长而淡 | 晨光微熹、清晨薄雾、露珠润物 |
| 正午 | 明亮、阴影短而锐、色彩鲜明：顶光为主（5200-5600K 中性），材质本色清晰、饱和度足，禁整片过曝死白 | 正午阳光、光线明亮、阴影短锐 |
| 黄昏 | 金色色调、长影、天空渐变：低角暖金 golden hour（2000-3500K）、长影拉地、天空由金向靛渐变（C5 金黄→C3 朱红晕→C4 靛蓝顶），灯笼初上 | 暮色金辉、golden hour、长影拉地、天空渐变 |
| 夜间（月光） | 冷蓝色调、幽静清冷：月光主光（6500-8000K 冷蓝，对齐全局色温），月白 C1 光面、靛蓝 C4 影部、墨黑 C6 剪影，能见细节收敛至轮廓与月照面 | 月光清辉、moonlight、冷蓝清幽 |
| 夜间（灯火） | 暖黄点缀、明暗对比：灯笼烛火（3000-3800K 暖黄）为唯一点光源，窗纸透暖光、光域收窄、明暗对比强，暗部入墨 | 灯火阑珊、烛光点点、窗纸透暖 |

### 时段衍生规范

| 从基准时段衍生 | 保持不变 | 变化项 |
|---|---|---|
| 日间 → 黄昏 | 建筑/布局/材质（L1 全锁，门窗陈设原位） | 天空色调暖化（白→金→橙红渐变）、影子拉长（太阳高度角降低、影向仍同侧）、光色转暖、灯笼/烛火渐次点亮（入夜时序） |
| 日间 → 夜间 | 建筑/布局/材质 | 整体变暗（环境光降、高光收缩）、灯具按古风时序点亮（灯笼/烛火为人工光源）、有月则叠月光冷蓝主光（灯暖月冷双层、主次分明）或纯灯夜（无月暗夜） |
| 室内日间 → 室内夜间 | 空间结构、家具（陈设原位不动） | 窗光消失→烛火/灯笼接管（3000-3800K 暖黄）、光域收窄至灯具周围、明暗对比增强、窗纸外透夜色（C4 靛蓝夜光，与室内暖光分色带） |

## 四、天候变体

### 天候定义

| 天候 | 视觉特征 | 提示词 |
|---|---|---|
| 晴天 | 明亮、阴影清晰（硬边锐影、天空清朗，天空由 C12 群青向 C1 月白浅化过渡，禁高饱和假蓝） | 晴空万里、阳光明媚、阴影锐利 |
| 阴天 | 光线均匀、无硬影：云层漫射（overcast）、主光方向消失、材质本色浮现无高光、色温偏冷灰（压抑或沉静随叙事） | 阴天柔光、overcast、无硬影 |
| 薄雾 | 能见度降低、空气朦胧：雾层近低远高（地面雾带/水面雾），远景虚化融入雾幕（空气透视增强，C4 雾蓝向），体积光光柱清晰可视（雾为介质） | 薄雾弥漫、雾气缭绕、雾带分层 |
| 细雨 | 水珠、湿润反光、雨丝：雨丝斜向粒子（近景可见丝、远景成雨幕），湿润表面高光升高（瓦面/石面湿亮）、地面积水洼面反光、色调偏冷（C4 灰蓝向） | 细雨如丝、雨幕轻纱、湿润反光 |
| 飞雪 | 白色覆盖、雪花飘落：积雪分层覆盖（屋面/地面/枝头，厚度符合降雪时长）、常绿枝叶挂霜压雪、色调偏白（雪面 C1 月白向、影部 C4 冷蓝向）、天空阴翳静谧 | 飞雪纷纷、银装素裹、积雪挂霜 |

### 天候衍生规范

| 从基准天候衍生 | 保持不变 | 变化项 |
|---|---|---|
| 晴 → 薄雾 | 建筑/布局（结构轮廓仍可辨认，禁雾吞主体） | 增加雾气层（浓度近低远高）、远景模糊（空气透视增强、雾蓝 C4 向）、饱和度降低、光柱可视性增强（介质条款） |
| 晴 → 细雨 | 建筑/布局 | 增加雨丝（斜向一致、近丝远幕）、地面反光（湿润 specular 升高、积水洼面映天光）、瓦面表面水流、色调偏冷（C4 灰蓝向） |
| 晴 → 飞雪 | 建筑/布局 | 增加积雪（屋面/地面/枝头分层覆盖，厚度合理）、雪花飘落（远小近大）、色调偏白（C1 雪面+C4 影部）、天空转阴翳 |
| 植被需随天候逻辑适配 | — | 雨中花瓣湿润贴枝、叶片垂珠、泥径湿亮；雪中枯枝挂霜、常绿松竹负雪压枝（弯垂弧度自然，禁夸张断折感）；雾中远景植被化入雾幕、近景叶面凝露 |

## 五、角度变体

### 角度定义

> 衍生图相对参考图，可在以下角度维度上进行切换。调用方会传入参考图 + 目标角度描述，本文件只定义角度语汇与一致性约束。角度切换=围绕场景同一中心点旋转机位，主体空间关系与光向不随之漂移（场景锚定/光向锁定原则），只改变取景方向与视高。

| 角度 | 描述 | 提示词 |
|---|---|---|
| 正面/前视 | 与参考图相比，视线朝向场景正面（主入口/主立面正对） | front view、eye level |
| 侧面（左/右） | 朝场景左/右侧 90° 平视（檐廊纵深/山墙形制可见） | left side view / right side view |
| 背面/后视 | 朝场景背面 180°（背立面窗位/后园/出入口关系可见） | back view |
| 俯视 | 高位俯瞰，呈现整体布局（屋面瓦垄排布、院落围合关系一览） | high angle、bird's eye view |
| 仰视 | 低位仰望，强调高大主体（檐下仰视见斗拱/藻井结构、压顶威压感） | low angle、worm's eye view |
| 近景推进 | 同方向但镜头推进，聚焦局部（朝参考图主视角沿纵深推进） | push-in、closer angle |
| 自由角度 | 调用方自定义的任意角度描述 | 按 `{目标角度}` 注入 |

### 角度衍生规范

| 项目 | 约束 |
|---|---|
| 参考一致性 | 建筑结构/布局/材质/色调/光线/季节/天候必须与参考图一致（L1 不变特征锁定：门窗位/通道/出入口/材质基底/主色全锁，仅机位变化） |
| 视点 | 同一场景中心点，仅角度切换；视线高度可随角度调整（平视约 1.6m 基准、俯仰角按叙事），主体建筑相对位置关系不变（禁角度一变布局重排） |
| 光照逻辑 | 参考图光源方向（日/月/灯位）不变，角度切换后光影投射方向需同步重算（保持物理合理：同一时刻同一太阳，墙体受光面与影向只随真实光位、不随机位旋转）——禁角度变体影向漂移、禁双天光 |
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 人物 | **严禁出现任何人物、人影、人体轮廓**（含剪影、倒影人形；人气以器物/旗幌/灯影等空镜元素承载，对齐 art_scene R5） |
| 画面比例 | 默认 16:9（或按调用方设定） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景空间结构在所有变体中保持一致（L1 锁定：柱网开间/屋脊/门窗位/通道/出入口，锚点场景识别特征任何景别角度不得消失） |
| R2 | 时段变体必须调整天空色调与氛围（天空渐变+色温切换+灯烛按古风时序亮灭；黄昏暖金长影 2000-3500K（体系黄金时刻口径）、月夜冷蓝 6500-8000K 与烛火 3000-3800K 对齐全局色温） |
| R3 | 天候变体必须适配植被/材质表面（雨=湿反光积水、雪=覆盖挂霜、雾=远物模糊），禁只加雨丝雪花粒子不改材质响应 |
| R4 | 衍生图必须为「单画面」，不得拼接多视图/网格/分屏 |
| R5 | 衍生图必须与参考图保持建筑结构/材质/色调/光线一致，仅按指定角度切换视点（机位绕场景中心旋转，光向不漂移） |
| R6 | 场景图中**严禁出现任何人物**：本体/人影/人体剪影/人体轮廓/倒影人形一概禁止 |
| R7 | 根据用户提供的信息自行判断变化维度（角度/景别/时段/天候），未提及维度留空省略（可叠加但主次分明、禁一次全维度同变致判断困难） |
| R8 | 必须包含3D渲染关键词（3D rendered / volumetric lighting / PBR materials），体积光须声明介质条款（尘埃/云雾/灵气光尘） |
| R9 | 必须包含镜头光学特征（depth of field / lens vignette / bokeh 至少一项，推荐配 focal point 明确焦点；景别推进时景深同步收浅） |
| R10 | 材质必须带有自然磨损/岁月痕迹（按使用与受力逻辑分布），禁止全新无瑕的"CG 感" |
| R11 | 输出前复核「变体一致五查」：结构布局一致/材质基底一致/主色一致/光向与季节天候一致/无人物无文字（逐项对照参考图） |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 变体间建筑结构/布局不一致（增减开间、移动门窗位、屋脊走向漂移、通道出入口重排） |
