# 国风3D约束 · 国风3D · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** — 全片以月白（C1）、青绿（C2）、靛蓝（C4）为基底色，整体色温偏中性（4800-5500K，对齐日间中性天光、防整体偏蓝偏黄失真），饱和度中高（55-75%，中高而克制），呈现传统东方美学的典雅大气色调（对齐传统色「雅」之最高标准：色不跳、不俗、不堆满，留白透气——月白 C1 是意境色而非精确数值，取「月色下的白、偏淡蓝灰、带清冷安静」之联想；精确取色以全局前缀核心色盘锁定的 #D6ECF0 为准，本句仅描述联想语义、不构成任何自由改色授权；青绿 C2 以石青石绿为物质基础，青绿山水千年不褪；靛蓝 C4 为蓝染体系核心，取「青出于蓝」语义）
- **情绪色盘驱动** — 六套情绪色盘（宫廷华贵/山水意境/闺阁温婉/武侠肃杀/节日喜庆/月夜清幽——对齐全局情绪色盘官方名：仙宫朝会/仙山云海/闺阁温婉/斗法激战/宗门庆典/月夜清幽；仙人降临/幽冥鬼域属神性/鬼域段落，按全局八套直接执行）对应不同叙事段落，色盘切换应与故事弧线同步（切换点即叙事转折点：同色相过渡可缓冲情绪、冷暖强反差直切可制造变故感，禁无动机的色盘漂移；段落内部禁跨盘取色——技法名六套与官方名八套的映射对照以全局前缀情绪色盘表为唯一权威，凡落色盘编号/主辅色组合一律回查前缀表执行，禁以技法名自行推导配色）
- **冷暖叙事对比** — 暖色（朱红 C3、金黄 C5、胭脂 C7、藤黄 C9）作为叙事转折的视觉信号，用于情感升温与喜庆段落（朱红 C3 为正赤之尊、正色秩序的载体）；冷色（靛蓝 C4、墨黑 C6）用于肃杀、忧郁、清幽段落；冷暖并置的明度/饱和度差即情绪张力，暖进冷退=情感升温、骤冷=变故转折
- **色盘先行原则** — 段落规划需先绑定情绪场景（宫廷华贵/山水意境/闺阁温婉/武侠肃杀/节日喜庆/月夜清幽等，官方名映射同「情绪色盘驱动」条括注，神性/幽冥叙事段落按全局八套直接执行），再确定主色+辅色与光影方案，避免"剧情对了但情绪不对色"（主色定情绪基调、辅色作点缀呼应，主辅同色系时用同类色微差出层次——汝窑天青与官窑粉青式的同系精微变化，先立色板再写镜头）
- **禁用色域** — 高饱和荧光色、霓虹色、现代数码色彩体系均与本风格不兼容（色盘仅取 C1-C15 传统色；间色系如紫属正色秩序之下的次级色，如作权谋/妖异叙事符号须刻意且少量，禁大面积滥用）

## 二、光影方案体系

- **光影即叙事** — 7 套光影方案对应不同情绪段落，导演规划阶段应在段落层面确定光影基调方向，而非逐镜指定（方案一经段落取定，该段落内光源方向/色温/季节天候全程一致、影向不漂移，跨镜措辞逐字复用）
- **3D渲染光影特征** — 体积光、环境光遮蔽（AO）、景深虚化为国风3D风格的核心光影手段，所有光影方案均须体现PBR物理材质渲染质感（体积光是能看到「光的厚度」的光，须借云雾/灵气光尘介质方可可视；AO 强化角落缝隙阴影层次、行业常用区间 0.5-1.0、全局初始 0.8 防暗部过黑（E 窗纱漫射案在方案表特化收窄至 0.5-0.8，属室内柔光档位特化，与全局区间互锁不冲突，同口径见分镜表设计的 3D渲染光影规范条）；景深虚化按叙事焦点取舍深浅）

| 光影方案 | 方案名 | 色调倾向 | 适用情绪 |
|---|---|---|---|
| A | 暖光华彩 | 朱红 + 金黄高光 + 月白底（暖金主光塑形，鎏金/琉璃/烛火灯笼层叠暖光 3000-3800K，局部高光提气，明暗对照克制成影，禁整片过曝） | 宫廷华贵、庄严气派、喜庆盛大（华丽庄严威仪，PBR 反射分层细辨） |
| B | 青绿意境 | 青绿 + 月白雾气 + 体积光漫射（丁达尔光柱借雾介质、空气透视近实远虚，雾气分层近低远高，低饱和清冷） | 山水意境、诗意悠远、空灵飘逸（留白构图，远景冷灰雾蓝化） |
| C | 柔光暖影 | 胭脂暖调 + 金黄点缀 + 柔和阴影（窗光/纱帐滤光漫射为软光，无硬边影，浅景深近景特写，烛光局部提亮妆面） | 闺阁温婉、柔美细腻、日常温馨（暖木 C8 衬底，皮肤通透无死黑） |
| D | 冷调肃杀 | 墨黑 + 靛蓝 + 硬光对比（low-key 低调：大面积暗部+局部小光，或分割光单侧硬光，硬边影高反差，低饱和） | 武侠肃杀、冷峻凌厉、氛围压抑（靛蓝墨黑入暗部，剑气寒光粒子可选） |
| E | 窗纱漫射 | 月白底 + 自然侧光 + 环境光遮蔽（overcast 单侧窗光漫射无主光方向感，AO 0.5-0.8 强化墙角屏缝暗部层次，阴影柔而浅） | 室内日间、日常起居、幽静雅致（中性自然，克制无戏剧化强对比） |
| F | 月夜清辉 | 靛蓝 + 月白冷光 + 金黄暖光点缀（月光冷蓝 6500-8000K 与暖灯烛火 3000-3800K 点状对置，blue hour 冷暖分色，暗部透气不糊死） | 月夜清幽、宁静唯美、思念独处（月光面 C1、夜天 C4、暖光点 C5 点睛） |
| G | 节庆暖光 | 朱红 + 藤黄 + 高饱和暖光（灯笼烛火 3000-3800K 点光源，红绸彩带高饱和暖色，克制不过艳禁荧光，人潮有层次近实远虚） | 节日庆典、热闹欢快、色彩丰富（暖光点点 C5、烟火绽于 C4 夜幕） |

- **冷暖光分配** — 暖色光（朱红/金黄/藤黄）适用于华贵、温婉、喜庆段落；冷色光（靛蓝/墨黑）适用于肃杀、忧郁、清幽段落。导演可根据叙事需要调整冷暖切换点（切换须有叙事动机，如场景更替/时辰流转/情绪骤变，禁无因跳变）
- **氛围方向映射** — 每场戏的氛围方向应能映射到上述光影方案（A-G）的某一方向，确保视觉一致性（一场戏可主方案+辅方案过渡，但主方案占比须 >70%，防风格碎片化）

## 三、质感方向

- **3D渲染为锚** — 国风3D的核心：高精度建模（次世代级高模，禁 low-poly）、PBR材质渲染、体积光、环境光遮蔽、景深虚化，呈现电影级3D渲染画面（光影手段齐全但服务于东方美学基调，不炫技）
- **PBR材质至上** — 所有服化道的材质必须通过PBR物理渲染可信：丝绸的光泽与垂感、木质的纹理与包浆、金属的反光与质感、玉石的通透与温润、瓷器的釉面光泽（工业参数口径：金属 Metallic=1.0、非金属=0.0 二分；金属 Roughness 常用 0.1-0.4、非金属 0.4-1.0（常规 0.6-1.0，丝绸缎面属低粗糙非金属特例取 0.4-0.6）；丝绸/瓷器属低粗糙高光、玉石以次表面散射 SSS 透光呈温润、木材以粗糙度 0.6-0.8 + 包浆高光错落显岁月；法线强度默认 1.0、微调 0.75-1.25）
- **体积光与景深** — 体积光是国风3D画面的灵魂：室外场景必须有空气透视与体积光散射，室内场景通过窗光/烛光制造体积光效果（借尘埃/雾气/灵气光尘为介质方可可视，光柱有厚度有衰减）；景深虚化强化空间纵深（焦点即叙事重心：情绪戏焦点落面部、空镜焦点落主体意象）
- **岁月质感** — 材质不可过于干净完美：木面有使用痕迹、石面有风化纹与青苔、布料有自然褶皱、瓦片有苔痕残缺。禁止"塑料感"和全新无瑕的"CG感"（磨损/包浆/苔痕入材质描述，是真实性的主要来源）
- **3D不等于冰冷** — 国风3D强调东方美学的温度感，通过材质质感、光影层次、色彩搭配传达情感，而非依赖奇观特效（温度感=暖色局部高光+柔化过渡+肤质通透有 C7 胭脂气色；禁大面积冷灰死板平渲）

## 四、古风场景空间元素

古风世界观特有的场景元素及其视觉叙事功能：

- **纱帘/屏风/门框** — 天然的框架式构图道具，制造"看不透"的层次感与空间纵深。3D渲染中纱帘的半透明材质与光线穿透效果是画面亮点（月白 C1 绢纱半透滤光、格扇月洞门作画框、屏风隔而不断，前景虚化层次可用）
- **庭院/花树/雨幕** — 留白构图的天然载体，景即情：满庭花开 = 释然、独坐雨中 = 孤寂、落叶纷飞 = 离愁。3D场景中植被的体积感与光影交互尤为重要（花树 C7 胭脂/花瓣粒子、雨幕斜织近丝远幕、落花簌簌为情绪写意）
- **烛火/月色/窗光** — 古风世界的光源载体，烛光 = 暖/私密（方案C）、月色 = 冷/清幽（方案F）、窗光 = 日常/静谧（方案E）。3D渲染中光源的体积光效果与PBR材质反射是关键（点光源逻辑唯一：烛火暖橘 C5 亮部、边缘即沉入暗部，光影随叙事时辰流转）
- **飞檐/斗拱/青瓦** — 古风建筑的标志性元素，3D建模需体现雕梁画栋的精致细节，材质需有岁月感（斗拱层叠出檐深远、瓦当滴水与青瓦苔痕、梁枋和玺/旋子彩画、汉白玉栏杆风化包浆，构件考据入句）
- **段落间用场景空镜过渡** — 本风格有丰富的场景资产（不同时段/天候/季节变体），段落衔接建议用场景空镜做情绪缓冲，不要硬切（空镜取上一段落的尾色与下一段落的首色作同色相承接或冷暖和弦，空镜即情绪转场）
- **转折点用视觉而非台词** — 优先使用画面手段（光影突变、景别跳切、空镜隐喻）而非依赖对白解释（情绪转折=光方案切换/色盘冷暖对置；叙事转折=景别跳切或意象空镜，台词只作补白）

## 五、古风乐器与环境音

古风世界观下的声音元素约束：

### 乐器选择

- **箫** — 凄凉、孤寂、悲戚段落的核心乐器，最能表现冷清哀婉（竖吹开管、音色苍凉悠远，配独白/空镜/远景抒情）
- **二胡** — 情感激荡、悲痛、思念段落，拉弦的哭腔感适合情绪爆发（滑揉音模拟悲泣呜咽，如泣如诉）
- **唢呐** — 情感波动剧烈段落（大悲大喜、命运转折、高潮），慎用但一用即核弹（命运高燃的「听觉引擎」：嘹亮音色冲破云霄、瞬间点燃情绪，可独奏亦可齐奏推高戏剧张力——对齐《哪吒》系「我命由我不由天」式声画共鸣用法；非高光段落禁用）
- **古琴** — 开场定调 / 平稳段落，与箫搭配使用，体现山水意境（七弦大音希声之留白、沉静定调，礼乐雅正之源）
- **琵琶** — 紧张、急促段落的点缀，武侠肃杀场景适用（武戏点弦急促、扫弦如战阵气势）
- **古筝** — 宫廷华贵、节庆喜庆段落的氛围乐器，华丽优雅（五声音阶华丽铺陈；亦可拟古器音色营造历史仪式感）
- 弦乐铺底可增加电影感但不宜喧宾夺主（主乐器在前、弦乐低音量衬底，声像留出主乐器呼吸位）

### 乐器组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 平稳/开场/收尾 | 古琴独奏 或 古琴 + 箫（沉静定调、余韵收尾，音量克制） |
| 山水意境/空灵 | 箫 + 古琴 + 笛（箫主哀远、笛主明亮空灵，琴作留白垫底） |
| 宫廷华贵/喜庆 | 古筝 + 编钟 + 弦乐（古筝华丽 + 编钟礼乐仪式感，弦乐铺华丽） |
| 悲戚渐浓 | 箫 + 二胡（箫先立冷清、二胡渐入哭腔，情绪递进不抢拍） |
| 情绪爆发/命运转折 | 唢呐独奏 或 唢呐 + 二胡（唢呐高光一瞬即收，二胡哭腔承接余韵） |
| 武侠肃杀/紧张 | 琵琶点缀 + 弦乐衬底（琵琶点弦制造急促，弦乐低音持续制造压迫） |
| 温婉日常 | 古琴 + 笛 + 轻弦乐（轻量织体、勿厚重，留出对白与环境音位） |

### 古风环境音

- **典型环境音层次** — 蝉鸣虫唱 / 溪水潺潺 / 风过竹林 / 市井叫卖 / 夜雨滴檐 / 衣料摩擦 / 风铃轻响 / 鸟鸣啁啾 / 落花簌簌
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计。环境音层次越丰富，古风场景越有沉浸感（声音分三层：环境铺底音+核心环境音+动作音，乐与声像平衡——对白/动作音在前、环境音居中、配乐垫底，核心环境音 1-2 个必须可辨，禁静音场景与配乐铺满）
