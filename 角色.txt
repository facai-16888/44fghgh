# 人物 / 魔兽异兽基础形象生成 · 约束手册

---

## 一、基础形象原则

1. **造型即灵魂** — 角色造型是核心锚点，风格基底锚定"3D半写实国漫 · 电影CG质感"（次世代建模、参考眷思量式CG渲染语言），国风3D造型，线条流畅如行云，造型先于妆造决定角色辨识度；面容整体锚定中国古典东方面孔（东亚汉人骨相），全部西化触发词（高鼻深目/深邃眼窝/棱角分明西式下颌/立体混血感）禁止进入角色提示词
2. **底模即基础** — 基础打底服装 + 素颜，后续服化均为叠加层；底模保持纯净无装饰残留、无既定表情，叠加层不反向污染底模
3. **四视图一致** — 面容/体型/发型/基础服装跨视图高度统一，同一张脸/同一体型/同一服装/同一配色/同一五官比例，建模阶段即锁定，禁止单视图特征漂移
4. **古典气质** — 无妆状态仍需体现角色气质（典雅/温婉/英气），气质须自角色设定提炼并具体化，全场景沿用不漂移
5. **原文即信息源** — 角色造型的一切视觉决策以剧本/小说原文为第一信息源：先扫全本该角色全部出场段落，摘录原文视觉词（服装颜色与质料/发式/标志物/印记旧疤/动作状态词），原文明确写出的视觉特征必须原文落词、禁自造或近似替换（剧本写"黑衣染血"即落墨黑 C6 底色 + 染血戏用状态登记，禁"深灰/藏青/素色"等近似漂移顶替原文）；原文未写明的项才允许按本手册默认值补位；服装底色/印记/发型一经原文锁定，全剧沿用不漂移；原文与各手册均未列的视觉元素按《全局美学基础》§五 未列元素推演条 四步推演并登记来源，禁新增编号
6. **提取四流分流（对症剧本/小说内容提取提示词）** — 剧本/小说的叙事语言是模糊的，模型无法区分哪些是可画信息、哪些是叙事背景，出图前必须先做提取分流——①身份特征流（脸型/瞳形瞳色/眉形/体型/契印旧疤胎记等印记=永久特征，原文落词、跨镜头跨视图恒定不漂移）；②造型选择流（服装/发型/配饰=可换层，核心服饰可作识别但按场可变，染血/破损/战损/湿透/泥污等戏用状态单列状态档不入底模，同规则5）；③临时状态流（表情/动作/天气/脏污=单画面变量，按镜头提取、不写入身份块）；④叙事信息流（性格/动机/身世/关系=不可直接入图，须转译为可见姿态或剥离——"眼神锐利的老侦探"属模糊叙事、须落可校验视觉词"眉弓下压+瞳仁聚光+目光锁定"，"右眉外缘纵向细疤"才是可校验视觉词；凡无法被看到的"童年创伤/不信任权威"等一律剔除或转译，禁空泛形容词充当视觉词入prompt）
7. **高信息量锚点优先（防"统计安全脸"与关键特征丢失）** — AI 默认生成"统计意义上更安全的脸"（对称/干净/无记忆点），契印、旧疤、胎记、瞳色异象、不对称发式等"高信息量特征"是打破安全脸的锚点：一个契印+一个瞳色异象>十个"俊美/清冷/好看"空洞形容词；提取时须给每个高信息量锚点精确解剖学位置（眉心/右眼睑外侧/左颧骨/后颈等，防左右镜像错误——正面观图中角色解剖学右侧印记显示在画面左侧，出图后须核查镜像）、原文落词并独立成锚行（见 §八 模板印记独立锚行），不得与其他五官描述混占一句稀释权重

## 二、面容约束

> 不预设单一五官模板，由角色描述（性别/年龄/性格/气质）驱动 AI 在国漫美化基准底线内（基准口径锚全局前缀二级风格「国漫美化面容」）差异化生成五官（底线：鹅蛋/瓜子脸非锥子、星眸杏眼或丹凤微挑、鼻梁挺秀——直而不过度隆起、山根平缓不高、下颌温润收敛非西式棱角、瓷玉肌底清透通透、SSS次表面散射透出血色禁哑光磨皮；禁锥子脸、日系超大圆瞳、网红整容脸、欧式混血五官；凡"高鼻梁/深邃眼窝/利落下颌/立体混血骨相"等词一律判为欧式骨相信号，改写为东方"挺秀平缓/温润收敛"表述）；五官一律以结构词成句（脸型/眼型/鼻型/下颌线等客观结构优先，AI 对"帅/美/立体/深邃"等主观泛化词会趋向欧美平均脸，对结构词才稳定还原），一经生成即锁定为角色唯一脸模，跨视图、跨镜头禁止更换。

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述自然推导，不预设单一五官模板，但必须落于国漫美化基准内（基准口径同本章，鹅蛋/瓜子脸非锥子、星眸杏眼或丹凤微挑、鼻梁挺秀山根不高、下颌温润收敛、瓷玉肌底清透通透SSS透出血色禁哑光磨皮），并以结构词成句（脸型/眼型/鼻型/下颌线结构描述，禁"高鼻梁、深邃、立体、混血"等西化触发词入prompt）；同角色全生命周期沿用同一脸模 |
| 颅面比例 | 符合国风审美中线（三庭五眼、轮廓清正），比例与骨相落于国漫美化基准带（国漫美化口径），不引入异域或现代特征；骨相显性呈现东亚汉人特征（眉骨平缓、眼窝不深、颧骨平展、鼻梁挺秀山根不高） |
| 风格底色 | 3D半写实国漫基底（眷思量式半写实CG锚定）、次世代建模、PBR物理材质、SSS次表面散射、电影级光影，细节密度对标影视级3D国漫主角色资产，国漫风格化比例（非日系二次元/非真人摄影写实） |
| 气质 | 必须从角色描述提炼整体气质关键词（如典雅温婉/儒雅英气/侠骨柔情），并写入提示词；气质词全场景复用 |
| 表情 | 中性微表情，符合角色气质；眼神有神采（按全局前缀 X12 锁神锚词口径执行——瞳孔有清晰高光落点 1-2 点钟位置单一高光不散乱、虹膜内透可见径向纤维纹理、眼白洁净无血丝、上眼睑紧实不下压不半闭、下眼睑微紧收、目光与镜头方向锁定 viewer eye contact、focused intense gaze 视线聚焦有压迫力；"冷冽/清正/温柔/典雅"为情绪气质禁渲成无神空焦，"冷"≠"空焦"、"清正"≠"空洞"、"温柔"≠"涣散"、"坚定"≠"凶"——禁眼皮半垂半闭、禁 droopy/half-closed/sleepy/tired/empty/vacant/lifeless/hollow gaze 软神态，与全局 dead eyes/blank stare 互补覆盖"无神空焦"全谱），唇部放松不绷紧，标准参照图不露齿不眯眼；异质标记若涉及瞳色异象以冷色微光可辨入prompt（如冷金/冰蓝/琥珀等，且仅限瞳孔区、不外溢成眼妆） |
| 异质标记 | 剧本/设定中明示的异质标记必须原文落词、明确可见度与材质词——契印类（眉心/手背/印堂/封号之印等）以暗色墨玉质感呈现、边缘清晰锐利、明确可见（原文未指定红色时禁渲成红/粉朱砂痣或装饰性眉心点；墨玉=近墨黑带青灰/黛青玉质、内敛低明度、半哑光无镜面高光、仅细润边缘微反光面积≤5%，禁渲成青绿/翠绿/蓝绿/翡翠/荧光/发光/宝石光/金属光/磷光/夜光/光晕光圈/刺目光斑；原文未指定颜色时默认墨玉/黑/暗灰青/黛青 系，绝不出现青绿/翠绿/翡翠/绿宝石/青蓝/冷蓝色），旧疤/泪痣/胎记以真实肤理凹陷或浅色印记呈现（与肤色过渡自然、不化入妆容），跨镜头位置与形态恒定不漂移 |
| 年龄呈现 | **自动推导年龄并显式落词**：剧本/小说未给年龄时，由线索（称谓辈分/修行境界/婚育经历/行文用词）自动推断设定年龄并写"设定年龄X岁"；由设定年龄映射视觉龄段词——少年12-17（骨相未定型、脸颊带稚、肤盈发密）、青年18-25（骨相初定、轮廓清秀、肤紧无纹、发质巅峰）、青壮26-35（骨相全定、下颌线收、肤质紧实或有薄纹）、中年36-50（骨相深定、肤质略沉、法令纹始现、两鬓可微霜）、老迈50+（骨相沉暮、眼周深纹、肤龄松沉、须发见苍），落词同步映射肤龄/发质/眼神与眉间纹，禁年轻脸配老气造型或反向错配；少年与老迈档不套用成年头身比唯一区间（头身比随身高档按 §四 同一映射比例同步收放、不设独立区间；落词以 §四 身高档与头身比档声明值为准，禁跨档套用成年男性 8.0-8.5 或成年女性 7.2-7.8 区间做美化）；同角跨场景年龄恒定不漂移 |

### 风格档挂载（A/B 面容基因）

> 本节为 §二 面容约束的**档位变量**，依据《全局美学基础》§四「A/B 双面容基因档」。作用：在不改动任何既有面容底线的前提下，为角色卡追加一个"结构处理方式与材质光影组织方式"的档位开关，使任意主流 AI 模型都能稳定产出同一审美取向的脸型建模——参考图只作观感标尺、图面内容禁入提示词（对齐全局前缀 X13）。

**档位定义**

| 档位 | 代号 | 结构处理方式（只决定"怎么处理"，不决定"是明是暗、是冷是暖"） |
|---|---|---|
| A 型 · 写实倾向档 | realism-leaning | 半写实CG的写实半边：骨相按解剖可信落地、五官体量接近真人尺度、面部碎结构（卧蚕/眼睑褶皱/唇珠）保留、肤质走实物级（细微微纹理+可见极细毛孔+绒毛感）、发丝单根可数至发梢收尖、材质以 PBR 物理通道为先、光影以柔和漫射光组织立体、明暗对照克制 |
| B 型 · 风格化倾向档 | stylization-leaning | 半写实CG的风格化半边：骨相做结构提纯、五官体量小幅理想化（限美化容差内、禁西化骨相与整容脸模板）、面部碎结构合并简化、肤质毛孔层级下调光泽更匀、发片分组清晰束感更强、材质以色阶分层与边缘光为先、光影允许主动硬光参与造型、明暗对照更明确 |

**落词口径**

- 档位只**追加**变量、不改写既有底线：东方汉人骨相（眉骨平缓/眼窝不深/颧骨平展/鼻梁挺秀山根不高/下颌温润收敛）、三庭五眼、国漫美化基准、素颜、SSS 透血色、锁质与锁神锚词一律照旧生效（X10/X13/X14 全表继续执行）。
- A 型与 B 型**均属半写实CG基线**：A 型禁用于要求"完全风格化/卡通化"的画面，B 型禁用于要求"完全写实/真人质感"的画面。
- 档位**不管情绪调性**：A 型可担夜戏与暗场、B 型可担日戏与亮场；明暗冷暖由情绪色盘与 A-I 光影方案决定，禁以风格档名义绕过色盘纪律。
- **建卡即锁档**：首版产出一经定档即写入角色卡元数据（造型备注区登记"面容基因档：A 型/B 型"），全剧不再改档；改档＝重出该卡全量资产；A、B 两档可在同片共存（如人族修行主线走 B、神族神战副线走 A），但**同一角色不得跨档**；双题材并存的片按**主线题材**锁全片基调（次要题材线仅该线角色与其专属场景/道具可另档），并在线别元数据显式标注题材归属以防跨线串档。
- **四环逐级继承**：角色卡 → 角色衍生（妆容服化） → 分镜（逐镜画面词） → 分镜视频（风格标签）必须继承同一档位代号，任一环缺失即判不合格。
- 群像卡（§十）与兽形（§十一）同样取档：同门派/同族系群像须统一档位、防族相漂移；兽形取档后骨相按兽形规则另行落词，档位只约束材质与光影组织方式。
- **定档判据与留痕**：角色卡的档位是**全体系档位的唯一源头**，须按《全局美学基础》§四 4.4「定档判据」五条线索（族属/血脉、叙事写法、视觉设定、镜头语言、题材映射）加权判定，命中项随卡片元数据留痕；其中**题材映射为首要线索、其命中票按两票计**——先判作品级题材（**人族修仙/玄幻/奇幻题材落 B 型**、**神族神话题材落 A 型**），题材线索与角色级线索冲突时以题材线索为准（如神族题材中的凡人侍从随题材落 A、人族修仙题材中的伪神反派随题材落 B）；**禁凭单一角色标签词直接落档**——某角色台词出现"神族"字样不足以定档，须看该角色是写成正统神性/写实向（偏 A）还是异质血脉/奇观强造型（偏 B），族属常以"承血者/旧朝余脉/天枢阁"等未直呼其名的方式书写；题材亦不明时落 A 型兜底并登记"档位待人工复核"（对齐全局前缀 R13 / X16）。
- **档位外供（本卡是源头、下级只继承）**：该角色名下的一切资产不自立档——其居所/法器/本命物/随身物/衣饰（见《art_scene》《art_scene_derivative》《art_prop》《art_prop_derivative》）须标注"继承自本卡"；其族系/门派共用资产（神殿、宗祠、族徽、山门、制式法宝）须标注"继承自本族系首例卡"；分镜与分镜视频逐镜继承本卡档位。同族系群像须与首例卡同档，防族相漂移；同镜多角色跨档并置时，画面风格以该镜主体角色档位为准，其余角色保留各自面容基因（对齐全局前缀 R14 / X17）。
- 未声明档位即判不合格（§九 R16）；兼容存量卡片时按 **A 型 · 写实倾向档** 兜底（全体系默认锚定眷思量式写实倾向半写实CG），并在验收单登记"档位待补"——存量卡批量补档时须先按作品级题材线索校正（**人族修仙/玄幻/奇幻题材的存量卡应校正为 B 型、神族神话题材校正为 A 型**），不得以兜底值直接充当已定档；"档位待补"（存量卡缺档）与"档位待人工复核"（判据判不准）同属**待办建档**，两类标签统一汇总于同一复核清单，不得作为"已定档"计。

## 三、肤感约束

### 女性

| 项目 | 约束 | 提示词 |
|---|---|---|
| 肤色 | 粉白基调、全身均匀、白皙透亮，肤色透出隐约血色不显苍白（粉白肌底取全局色盘 C1 月白系淡色、取向暖调，唇颊血色仅以 C7 胭脂作通道锚定，非整面取色；禁冷调漂白——冷白易触发欧式苍白观感） | 粉白基调、白皙透亮、透出血色（月白暖底、禁冷调漂白）、3D建模肤色 |
| 光泽 | PBR材质渲染、自然光泽、非哑光，带次表面散射的通透瓷感、不泛油光 | PBR材质渲染、SSS次表面散射、自然光泽、柔和质感 |
| 质感 | 高精度建模、纹理清晰、边缘柔和，细腻肤质、保留自然皮肤质感与细微微纹理呼吸感、暖调底色（粉白/月白暖底）透出隐约血色、非塑料非蜡像，禁过度磨皮哑光娃娃肌/冷调漂白/苍灰惨白/过曝高光压平纹理 | 细腻肤质、自然皮肤质感、细微微纹理、暖调底色透出血色、高精度建模、纹理清晰、边缘柔和 |
| 露肤 | 面部/颈部/手部，露肤区域与面部色差不超过1档 | 手部细腻、颈部线条柔和、肤色均匀 |

### 男性

## 十一、魔兽/异兽/灵兽类 · 非人角色基础形象扩展

> 本章为 §一-§九 人类角色口径的**非人角色扩展**，用于魔兽/异兽/灵兽/神兽等兽形生物的基础形象生成；凡本章未尽事项一律沿用本手册通用纪律（四视图一致、底模纯净、原文即信息源、四流分流、统一负向词块与锁质锚词投喂），以下仅列兽形专属差异项。
>
> **编号口径**：本章 R/X 编号**续 §九 人类章序连续排布**（人类章 R1-R18 / X1-X20，本章 R19-R32 / X21-X34），本手册内不重号、不跳号；与其他手册的同名局部编号（如《art_prop》X11、《art_scene》X15）**不同义**，跨手册引用时必须带手册名。档位纪律与人类章同源：定档判据与档位外供见 §二 落词口径及 §九 R18 / X20，兽形取档后骨相按本章规则另行落词、档位只约束材质与光影组织方式。

### 基础形象原则（兽形）

1. **种族即灵魂** — 兽形造型是核心锚点，风格基底锚定"3D半写实国漫 · 电影CG质感"（次世代建模、参考眷思量式CG渲染语言），3D玄幻兽形，造型先于毛羽鳞甲决定种族辨识度；兽形骨相锚定东方玄幻谱系（龙/蛟/虎/狼/鹏/犀/螭/麒麟等），全部现代野生动物摄影触发词（photorealistic animal、写实野生动物摄影、纪实毛发汗毛级）禁止进入兽形提示词
2. **底模即基础** — 基础素毛/素鳞 + 无装具，后续兽甲/鞍具/契约纹饰均为叠加层；底模保持纯净无属性特效残留、无既定姿态（参照姿势），叠加层不反向污染底模（兽甲/鞍具/契约纹饰等兽具叠加口径见《art_character_derivative》§十一 非人角色衍生扩展）
3. **多视图一致** — 兽颅骨相/体型/毛羽鳞甲/基础比例跨视图高度统一，同一头骨/同一体型/同一毛色/同一瞳色/同一比例，建模阶段即锁定，禁止单视图特征漂移
4. **血脉气质** — 无特效状态仍需体现种族气质（威压/灵动/凶戾/祥瑞），气质须自设定提炼并具体化，全场景沿用不漂移；凶兽≠口水横流、祥瑞≠纸片卡通，气质一律靠骨相与姿态落词
5. **原文即信息源** — 兽形视觉决策以剧本/小说原文为第一信息源：先扫全本该兽全部出场段落，摘录原文视觉词（毛色/鳞色/角数/瞳色/异纹/体型/兽龄），原文明确写出的视觉特征必须原文落词、禁自造或近似替换（原文写"通体雪白"即落月白 C1 毛色，禁"浅灰/银白"漂移顶替）；原文未写明的项才允许按本手册默认值补位
6. **提取四流分流（对症剧本/小说内容提取提示词）** — ①血脉特征流（角数/瞳色异象/异纹/契纹/兽纹=永久特征，原文落词、跨镜跨视图恒定不漂移）；②造型选择流（毛羽鳞甲形态/兽龄体态=可按场可变，伤损/染血/焦痕等戏用状态单列状态档不入底模）；③临时状态流（兽吼/扑击/受击/气息外放=单画面变量，按镜头提取、不写入血脉块）；④叙事信息流（凶名/血脉等级/上古来历=不可直接入图，须转译为可见形体或剥离——"上古凶兽"属模糊叙事、须落可校验视觉词"骨相厚重+瞳仁竖裂+鳞甲叠刃"；凡无法被看到的"万兽之王/活了千年"等一律剔除或转译，禁空泛形容词充当视觉词入prompt）
7. **高信息量锚点优先（防"通用野兽脸"与关键特征丢失）** — AI 默认生成"统计意义上更安全的兽形"（对称/干净/无记忆点），角数、瞳色异象、异纹、契纹、断牙缺耳等"高信息量特征"是打破通用兽形的锚点：一个异纹+一个瞳色异象>十个"威猛/霸气/恐怖"空洞形容词；提取时须给每个高信息量锚点精确部位（额心/左眼/颈侧/背脊/尾梢等，防左右镜像错误——正面观中兽体解剖学右侧印记显示在画面左侧，出图后须核查镜像）、原文落词并独立成锚行，不得与其他骨相描述混占一句稀释权重

### 兽形约束

> 不预设单一兽形模板，由兽种描述（血脉/属性/兽龄/气质）驱动 AI 在国漫玄幻兽形基准底线内（底线：骨相厚重不呆板、瞳形按兽种分型——竖裂瞳/环纹瞳/竖瞳、鼻吻按兽种结构、利齿外露克制不流涎、毛羽鳞甲量感完整；禁西式龙套用兽、禁写实野生动物摄影骨相、禁卡通圆头大眼萌化、禁廉价怪兽玩具塑料感；凡"写实动物摄影/毛发根根可数到汗毛级"等词一律判为纪实信号，改写为东方玄幻"半写实CG毛羽/鳞甲"表述）；兽形一律以结构词成句（头骨/吻部/瞳形/角形/四肢结构优先，AI 对"威猛/霸气/恐怖"等主观泛化词会趋向通用野兽平均形，对结构词才稳定还原），一经生成即锁定为兽种唯一骨相，跨视图、跨镜头禁止更换。

## 十二、非实体角色扩展（投影/法相/虚影/灵体）

> 人类章 §九 R1-R18 / X1-X20，兽形章 §十一 R19-R32 / X21-X34，本章 R33-R42 / X35-X44。本章覆盖无实体载体的"非实体影像类"角色：天道投影、法相/神通化身、魂体与灵体、识海虚影、全息幻象，以及由该类角色承载的浮空界面/系统面板体。此类角色共用 §一-§九 的元数据规范、档位继承（不自立档、随所属题材线）与多视图规范，材质与光照响应按本章覆盖项执行。

> 依据（2026-09 联网核验）：①全息/虚影/幽灵类材质的行业通行构成为「透明混合（Translucency）＋自发光（Emissive）＋菲涅尔边缘光（Fresnel rim）」三件套——Unreal Engine 官方将 Fresnel 节点列为"创建虚拟世界物体轮廓/边缘光"的标准用法，全息类材质普遍以边缘光（Rim Light）保证剪影可读；三件套缺一即会或读成实体人物、或糊成一团无从辨认。②浮空界面/面板类元素的世界观内实体化（diegetic UI）是影视与游戏界面设计的通行口径：UI 须作为叙事世界中的实体存在并建立统一的世界内视觉语言，避免"屏幕贴片"破坏沉浸。③面板类元素不得承载可读文字，与本手册及全局前缀 X7 口径一致——主流图像模型仍以"图像纹理"方式绘制文字而非文字排版，中文字符集庞大、笔画复杂，字数越多、字号越小、输出分辨率越低则错字/漏字/伪文字概率越高（行业实测结论：含小字号的画面文字不应指望模型直出）。

| R35 | **提示词模板锁定** — 非实体四视图提示词必须按 §十二 模板逐行组句，不得自行删行/合行/跳行；模板中的字段占位符必须替换为具体落词；模板含「面容基因档」声明行与对应整块基因词块（人形非实体取《全局美学基础》§四 4.2 人物向词块，无固定人形者取材质语言与光影语言两项），缺档、缺词块或未标注档位来源即判不合格（与 R36 材质三要素并行） |
| R36 | **材质三要素缺一即返工** — 透明＋自发光＋边缘光必须同框可辨；输出后按"是否读成实体人物／是否糊成一团"二问验收 |
| R37 | **戏用状态不入底模** — 剧本/小说中的戏用状态词（裂解/崩解/被蚕食/光衰/被锁链贯穿等）只登记入非实体卡"造型备注·戏用状态"档、对场次单出，不得写入基础形象底模描述 |
| R38 | **原文落词** — 设定明写的形态/光色/体内纹样须原文落词＋精确部位＋材质词，独立成锚行，跨镜位置形态恒定；原文未指定光色时默认按所属光影方案光色或墨玉/黛青系 |
| R39 | **面板体零文字** — 面板画面内不得出现任何可读文本与数字，信息由台词/旁白/环境音承载；面板须作世界观内实体影像处理（灵气光纹/符箓投影/契印纹路展开），禁贴片式平面 UI |
| R40 | **多视图规范** — 按 §七 四视图（头部特写/正/侧/后）执行，非实体特有项：剪影边界锐利可辨、透明度层级四视图一致、体内纹样布局四视图同源、光色四视图同色 |
| R41 | **数值与容差** — 自发光以发光强度与 HDR 泛光呈现，最亮处须保留轮廓与色相、不泛白丢失边界；透明度以"可透见背景但剪影可辨"为准，禁高到看不见、禁低到读成实体 |
| R42 | **全生命周期恒定** — 形态、光色、透明度层级、体内纹样一经定档，全剧跨场跨镜恒定不漂移；戏用状态变化按 R37 单出 |

**严禁（非实体）**

| 编号 | 严禁 |
|---|---|
| X35 | 读成实体人物（可见皮肤毛孔/汗毛/布料纤维、有落地硬投影与投影遮蔽、被环境光正常照亮） |
| X36 | 材质三要素缺失：无边缘轮廓光（只剩半透明色块），或无可自发光核心（靠环境光才亮） |
| X37 | 半透明过度糊成一团、剪影边界模糊不可辨，或透明度过低读成实体 |
| X38 | 自发光泛白过曝、最亮处丢失轮廓与色相（白到边界消失） |
| X39 | 光色不查色盘、跨镜换色，或荧光/霓虹高饱和（对齐全局前缀 X2 与美学禁止项） |
| X40 | 面板体出现可读文字、数字、现代 UI 框线/图标/进度条，或贴片式平面 UI 悬浮于画面之上 |
| X41 | 体内纹样/符文布局逐镜重排、增减分支、镜像换形（同场结构性纹样每镜变形＝空间崩坏） |
| X42 | 体量无因涨缩，或投影本体与其"影子/倒影/法身残像"混用导致空间关系错乱 |
| X43 | 以"鬼片白纱/烟雾人/贴图鬼影"廉价手法替代（非国漫3D基底，判据同 X29） |
| X44 | 反美颜bias投喂不完整——非实体类提示词未携带 §十一 统一负向词块与锁质英文锚词即投喂：漏投=发光糊块+柔焦雾化+纹样贴纸化（同全局前缀X11/X12口径）；输出提示词时负向词块与锁质锚词必须随主prompt成块附带、禁省略禁截断 |
