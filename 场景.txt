# 场景图生成 · 约束手册

---

## 一、场景美学原则

1. **空间叙事** — 场景承载情绪与叙事功能，不是纯背景板：先锚定时空（什么年代/什么地域/发生过什么事件），让每个视觉元素都能回答「世界为什么会变成这样」；无人物场景以动态叙事与空镜人气表达故事感——运动冻结（飞鸟展翅定格、水面波纹扩散）、力的积蓄（门半开、索绷直、尘屑下落）、事件回波（涟漪未平、帘幔微动、茶烟尚温），让观众看见「事件刚发生的结果」，禁空泛壁纸感
2. **层次纵深** — 所有场景必须具备前/中/后景，杜绝扁平：每层各有内容物与光影承接（前景框景枝叶/中景主体建筑/后景远山雾幕），纵深以大气透视（空气透视）推进——离镜头越远越模糊、色度越淡，远景整体向冷灰/雾蓝偏移（C4 靛蓝/C10 素灰向，国画「远山如黛、近实远虚」口径），禁无远近关系的平铺直叙
3. **质感至上** — 木质/石质/布料/水面等材质纹理必须超清晰：PBR 物理材质多通道（基色/粗糙度/金属度/法线分层），材质微结构可见（木纹年轮、石面风化、布织经纬、釉面微划痕），并携带自然磨损/青苔/包浆等岁月信息，细节密度对标影视级 3D 国漫资产，禁塑料玩具感与平涂无细节
4. **3D为锚** — 一切画面以 3D 半写实国漫渲染为锚（3D写实渲染管线，场景本体无面容，风格基线同全局前缀），拒绝 2D 平面贴图感、低质 3D 渲染与廉价 CG 动画塑料质感；追求体积光（光柱须借助尘埃/云雾介质方可可视，仙侠口径=灵气光尘）、环境光遮蔽、全局光照、HDR、景深虚化等电影渲染效果，禁死白无层次、禁纯 2D 插画平涂

## 三、室内场景

### 空间规范

> 室内尺度/结构纪律：AI 生成室内图最高发翻车是「尺度失真 + 结构断连 + 重复构件复读错乱」——落词必须给物理尺寸锚（层高约 3m、门高 2.4m、桌案高 0.75m、坐具高 0.45m、床榻长 2m、窗台 0.9m），家具须落地贴地、与地面有接触投影，禁悬浮穿墙；室内透视默认人眼视高（约 1.6m），一点/两点透视灭点一致、墙体横平竖直，禁广角畸变与透视歪斜；重复构件（柱列/格扇窗/栏杆/灯列）间距均匀、数量可数，禁复读式错乱堆叠；同屏家具尺度成组自洽（书案配圈椅，不配巨型床榻）。

| 维度 | 约束 | 提示词 |
|---|---|---|
| 风格 | 古代宅邸/宫殿/书房/闺阁，形制锚定唐宋至明清（唐宋出檐深远、斗拱雄大、线条舒朗；明清构架繁密、彩画细巧），分北方官式（庄重恢弘）与江南文人（素雅灵秀）两路口径，跨区不可硬拼 | 古代{朝代}风格，{北方官式/江南文人}一路 |
| 材质 | 木质为主、石/玉/绢/纱为辅：柱枋暖木 C8 赭石向，局部构件入考据词（格扇可拆、挂落=额枋下透雕花格、雀替=梁柱交角三角木雕、藻井穹窿象天、落地罩/博古架隔断、月洞门），石质 C10 素灰向、绢纱 C1 月白 | 檀木家具、玉石屏风、绢纱帷幔、格扇雕花、朱红立柱 C3 |
| 色调 | 中国传统色调：月白纱幔 C1 + 朱红木漆 C3 + 暖木 C8 定底，金线描彩 C5 局部提气（描金彩画/鎏金铜饰克制分布）；明度中高、暗部透气，禁整体糊黑 | 暖木色调、素雅陈设、描金提气 |
| 纵深 | 前/中/后景层次各自落物：前景框景（格扇/案几/垂帘）、中景主体（家具陈设/屏风）、后景深远（内室/回廊/窗景借景）；层间以帷幔/屏风/落地罩制造递进与「藏」的意趣（园林欲扬先抑法入室内） | 前景{元素}、中景{元素}、后景{元素} |
| 质感 | 木纹/布料垂感/瓷器光泽可辨：PBR 微结构可见（木纹年轮、织纹经纬、釉面光泽、绢纱半透），接触与陈设逻辑合理 | 纹理清晰、材质质感精细、微结构可见 |
| 光照 | 自然光源为主：昼=窗光天光漫射（5200-5600K），夜=烛光/灯笼（3000-3800K 暖黄，对齐全局色温）；烛焰以多层光源叠模拟摇曳；体积光（光柱经尘埃/灵气光尘可视）、窗棂投光格影（格扇漏窗在地面/墙面投出雕花光斑，对齐花窗之美）、环境光遮蔽落于墙角与家具体量交界 | 自然光漫射、烛光暖黄、窗棂花影、体积光 |
| 镜头感 | 景深虚化前后景、镜头暗角、色散微痕：焦点明确（焦点处细节最锐），默认 35-50mm 叙事视角，空间纵深可浅景深分层强调；禁无焦点的平铺全景 | depth of field、lens vignette、chromatic aberration、focal point |
| 瑕疵感 | 岁月痕迹按使用逻辑分布：木=门轴磨亮、扶手/案沿包浆、漆面局部剥落露底；石=门槛踩踏处磨圆、地面接缝积尘；布=自然垂褶、洗晒微褪色；铜器=氧化斑（红斑绿锈按环境分布）；禁全件糊脏、禁噪声贴图淹没材质辨识 | 岁月痕迹、自然磨损、包浆集中于接触处、布料自然垂褶 |

## 五、主视图规范

### 视图定义

> 单画面主视图，从场景中最具代表性的角度拍摄，承载空间叙事与构图重心。确立时空锚点后再定镜头（先答：什么世界/什么年代/发生过什么），构图三锚写死——主体位置、景深分层、光源方向，三锚定了再铺细节；无人物场景以人体测量参照物校准尺度（门高约 2.4m、窗台 0.9m、栏杆 1m、台阶 15cm，替代人体作比例锚），禁无参照大空镜比例失衡。

| 项目 | 约束 | 提示词 |
|---|---|---|
| 视角 | 自然观察视角，构图最能体现场景主体与纵深：hero shot 代表角度、场景主体清晰、纵深引导线明确（路/廊/溪/林隙引向主体或天际），禁平庸游客照视角 | hero shot、representative angle、leading line |
| 视点高度 | 默认人眼平视高度（约 1.6m 视高基准），特殊场景可俯（俯瞰园林全景/登高远眺）/仰（宫阙威压、塔楼仰视），俯仰须与叙事意图一致，禁随手歪斜视角 | eye level（默认）、high angle、low angle hero |
| 构图 | 主体居中或符合三分法，前/中/后景层次清晰；焦点明确（焦点处细节最锐、景深向两端渐虚），平衡构图、天际线/地平线平正不歪 | balanced composition、rule of thirds、clear focal point |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 人物 | **严禁出现任何人物、人影、人体轮廓**（含剪影、皮影化侧影、远景火柴人、水面倒影中的人形；市井烟火仅以器物/旗帜/灯影等空镜元素承载） |
| 一致性 | 风格/材质/色调/光线统一（场景色对齐全局色盘，主色克制 ≤3 个主色层级，禁彩虹堆砌） |
| 光线 | 单一光源逻辑，光影方向一致（日影/烛光/月光三者互不打架，倒影与光源同向） |
| 画面比例 | 默认 16:9（或按调用方设定） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景必须有「前中后景层次」，每层各有内容物与光影承接，禁无远近的扁平平铺 |
| R2 | 室外必须包含「空气透视」：远景冷灰/雾蓝化（C4/C10 向）、近实远虚、以介质颗粒推进纵深 |
| R3 | 场景图必须为「单画面主视图」，不得拼接多视图/分屏/网格（对齐 X6） |
| R4 | 构图须能代表场景主体并展示前/中/后景层次；主体位置+景深分层+光源方向三锚写死，焦点明确 |
| R5 | 场景图中**严禁出现任何人物**：人物本体、人影、人体剪影、人体轮廓、倒影中的人形一概禁止；市井人气只能以器物/旗帜/灯笼/炊烟等空镜元素承载 |
| R6 | 必须包含3D渲染关键词（3D rendered / volumetric lighting / PBR materials），体积光须声明介质条款（尘埃/云雾/灵气光尘） |
| R7 | 必须包含镜头光学特征（depth of field / lens vignette / bokeh 至少一项，推荐配 focal point 明确焦点） |
| R8 | 材质必须带有自然磨损/岁月痕迹（按使用与受力逻辑分布），禁止全新无瑕的"CG 感" |
| R9 | 尺度须可读：无人物画面以人体测量参照物校准比例（门高约 2.4m/窗台 0.9m/栏杆 1m/台阶 15cm 等比锚），禁无参照导致建筑与人尺度失衡（微型庙/巨物亭）；室内补室内锚（层高约 3m/桌案高 0.75m/坐具高 0.45m/床榻长 2m），桌椅柜榻须接地有接触投影、禁悬浮穿墙、禁重复构件复读错乱 |
| R10 | 季节/时间/天候与光源逻辑自洽：昼=天光（5200-5600K）、夜月=冷蓝（6500-8000K）、烛火=暖黄（3000-3800K），倒影与光源同向，禁昼夜光混打 |
| R11 | 场景色对齐全局色盘编号取色（主色 ≤3 层级、点缀克制），禁高饱和荧光/霓虹数码感（对齐全局 X2） |
| R12 | 输出前复核「无人物五查」：人物本体/人影/剪影/轮廓/倒影人形，并复核无文字上屏 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 背景纯白/纯黑/无场景（纯黑=无环境光死画面；L3=全局美学色彩例外机制，仅梦境/心魔幻境/重大节庆临时场景须显式声明「本镜头启用 L3 例外」方可出，无 L3 声明禁出——与人物衍生手册 L3 中衣记号无关） |
| X2 | 极端天候（暴风雨/雷电/暴雪/龙卷等，除非剧情需要并显式声明） |
| X3 | 场景无纵深/无层次 |
| X4 | 植被/天候与季节矛盾（桃花雪地无逻辑、水乡配旱生植被、雪线长热带植物、荷花红叶同框等气候带错误） |
| X5 | 出现任何人物、人影、人体剪影或人体轮廓（含皮影化侧影、远景火柴人、水面倒影人形） |
| X6 | 画面被拼接成多视图/网格/分屏布局 |
| X7 | 低精度建模/粗糙贴图/塑料质感（禁用 low-poly、rough modeling 等词） |
| X8 | 材质过于干净完美、无任何使用痕迹与岁月感（避免"塑料感"） |
| X9 | 光照过于均匀平坦、无景深虚化、无镜头光学特征（无焦点、无明暗节奏的死平光） |
| X10 | 现代工业元素混入古风场景（路灯/电线杆/汽车/柏油路/现代招牌/霓虹/水泥高楼/电子屏等）；室内禁现代照明与电气件（吸顶灯/日光灯管/LED灯带/现代玻璃罩台灯/电线插座/开关面板），照明唯烛火、烛台、灯笼、油灯 |
| X11 | 形制/地域混搭穿帮：跨朝代硬拼（唐宋斗拱配明清繁彩画）、南北风格同框错乱（北方官式+江南水乡布局无叙事依据） |
| X12 | 全画面柔焦雾化磨糊（以雾遮细节当氛围、无焦点的整体雾化）；雾只许作内容性氛围元素——雾带/雾幕/天候薄雾分层渲染，近景与焦点处材质纹理仍须锐利清晰（空气透视近实远虚、体积光借云雾介质属合法纵深手段，不在禁列） |
| X13 | 生态/气候矛盾与建筑水体穿帮（无源死水、沙漠种荷、倒影方向与光源相反、水面无反射） |
| X14 | 透视/比例/物理穿帮：地平线歪斜、天际线错乱、建筑比例失衡（尺度无参照）、漂浮悬空建筑、穿模叠构 |
