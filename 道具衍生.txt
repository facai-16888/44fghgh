# 道具衍生状态生成 · 约束手册

---

## 一、衍生原则

1. **造型锚定** — 基于道具设定图/底图衍生（固定seed、参考图锚定），道具核心造型/轮廓/件名结构（如剑=刃脊格首鞘、玉佩=形制纹样）在所有状态中可识别；L1 不变特征层全程锁定（造型轮廓+材质基底+主色），状态只发生在材质表面与结构损伤层，禁状态变体顺手改款改形
2. **状态可读** — 状态差异必须一目了然、观众能立即区分：以可测量的行为痕迹与损伤形态落词（磨损分布、缺口形态、色相氧化、包浆深浅），以行为痕迹替代抽象形容词，禁含糊堆词导致状态不可辨
3. **叙事服务** — 每种状态变体服务于特定剧情节点（新铸出鞘/百战之兵/断剑遗物/染血信物/封印法器等），状态梯度与剧情因果吻合，同一道具跨状态前后连贯可衔接
4. **渐进退化** — 损伤/老化状态有合理物理逻辑并分级推进：先表层后结构（磨损→划痕→崩口→断裂、泛黄→发脆→碎裂），损伤分布服从受力与接触逻辑（刃口先卷崩、器足先磕缺、纸本先水渍霉斑），禁玉石生锈、木器沁色等跨材质错误
5. **纯道具独立展示** — 画面中只能出现道具本身，严禁出现任何人物、手部、肢体；道具不可处于被持有/佩戴/握持/使用中的状态，不可出现暗示人物存在的元素（手持痕迹、佩戴视角、使用姿态）；与道具设定图同口径——静物陈列独立呈现（平置/架放/自然悬浮——悬浮按法宝设定含灵力悬浮逻辑，禁无逻辑物理漂浮；稳定不飘浮、无人体接触件），仅状态层变化

## 二、状态类型

### 2.1 使用状态

| 状态 | 描述 | 适用道具 | 提示词 |
|---|---|---|---|
| 崭新 | 完好无损、光泽如新：无任何使用痕迹，抛光/釉光/织纹完整，无包浆无划痕（新登场/新铸/新制节点） | 所有道具 | 崭新、完好无损、光泽如新、无使用痕迹 |
| 日常使用 | 微磨损、自然包浆：磨损集中于握持缘/刃口/器足等接触受力部位，包浆薄匀、划痕浅细，整体结构仍完整 | 兵器/器物/饰品 | 日常使用痕迹、自然包浆、浅细划痕集中于接触部 |
| 陈旧 | 明显年代感、色泽暗淡：包浆加深、色相沉入（金属氧化、木色转深 C8 赭石向、纸本泛黄），边角圆钝、小损累积，造型仍可辨认 | 器物/信物/卷轴 | 古旧斑驳、年代感、色泽暗沉、边角圆钝 |

### 2.2 损伤状态

| 状态 | 描述 | 适用道具 | 提示词 |
|---|---|---|---|
| 微损 | 小裂纹/小缺口/轻微磨损：瓷器口部磕缺（口磕）或细冲线、玉佩微绺、刃口微卷崩，结构完整、功能未失 | 瓷器/玉佩/兵器 | 细微裂纹、轻微缺口、冲线微裂 |
| 破损 | 明显裂缝/断裂/破碎：瓷器冲线贯通或炸纹放射（鸡爪纹）、玉绺加深成裂、金属卷刃崩口断刃、纸质撕裂，主体仍存 | 瓷器/饰品/兵器 | 裂缝明显、碎裂、断裂、崩口 |
| 残片 | 仅剩部分/碎片：断口/缺角清晰，残件保留原造型特征（半块玉佩、断剑残刃、缺角碎片），叙事焦点在「缺失」本身 | 瓷器/玉佩/信物 | 残片、碎片、仅存半块、断口清晰 |

### 2.3 特殊状态

| 状态 | 描述 | 适用道具 | 提示词 |
|---|---|---|---|
| 染血 | 血迹附着：按陈旧氧化色相呈现（暗红转褐黑，对齐 C3 朱红/C8 赭石降饱和向），分布克制且有叙事逻辑（刃面擦痕、信物溅斑），禁鲜红喷溅与大面积浸染 | 兵器/衣物（未穿着，平铺/架置陈列）/信物 | 血迹斑驳、陈旧血渍、暗褐氧化、分布克制 |
| 浸水/湿润 | 水渍、湿润反光：纸本吸水皱缩、边缘晕开、墨迹洇散，湿润高光分区克制；禁整面湿透糊作一团失去材质辨识 | 卷轴/信物/衣物（未穿着，平铺/架置陈列） | 浸水、纸张湿润、墨迹晕染洇散 |
| 燃烧/焦损 | 焦黑边缘、火烧痕迹：边缘焦黑卷曲起翘、碳化斑自边缘向内部渐变、烟熏痕迹，范围克制不吞没主体 | 卷轴/信物/木质品 | 边缘焦黑、火烧痕迹、烟熏碳化、卷曲起翘 |
| 发光/激活 | 内在能量、光芒四射：法器铭文亮起 C5 金黄、玉石内蕴光华（内透光 SSS 增强），光效克制不遮本体、不禁锢识别 | 信物/法器/玉石 | 微微发光、内蕴光华、铭文亮起 |
| 包裹/封存 | 用布/盒子包裹：锦布/木盒封存（束带系口/系带/合拢），须露出可辨认局部（柄端、系孔、一角、束口）维持道具识别 | 信物/饰品/秘物 | 锦布包裹、木盒封存、局部显露 |

## 三、状态变体画面规范

### 单状态图

| 项目 | 约束 |
|---|---|
| 背景 | 素灰纯色 #B8B8B8（与设定图一致），四宫格底色完全一致 |
| 光线 | HDR柔和环境光、均匀柔光、无硬阴影、允许自然地面微投影（软接触影）；状态新增高光（湿润反光/发光）须与主光向一致，不产生镜像高光错乱 |
| 角度 | 与原设定图各视图角度一一对应（四宫格正面图对齐设定图正面图，同一朝向同一透视/视高），仅状态层差异，禁顺手改角度改视高 |
| 比例 | 道具占画面主体 70%+，状态细节（损伤/痕迹/反光）在格内清晰可辨 |

### 状态对比图

| 项目 | 约束 |
|---|---|
| 布局 | 同一画面并排展示 2-3 种状态（横向等距排布），各格背景/视高一致、无重叠无跨格 |
| 标注 | 每种状态下方标注状态名（出图流程中以编号图注管理，画面本体不叠文字上屏，对齐全局「无文字」禁则） |
| 一致性 | 角度/光线/背景完全一致，仅状态层差异（L1 不变特征锁定，同一造型同一材质基底同一主色） |

## 四、材质状态变化规则

| 材质 | 崭新 → 日常 | 日常 → 陈旧 | 损伤表现 |
|---|---|---|---|
| 金属 | 亮光泽 → 微包浆：高光仍清，握持缘/刃口出现浅划痕（多向细划痕网络，edge wear 由边缘向内） | 包浆 → 锈蚀斑点：色相沉暗，氧化斑/红斑绿锈（铜器）按环境与接触分布，棱角磨圆 | 缺口/卷刃/崩口/断裂：刃口先卷崩（卷刃=软刃弯卷、崩口=刃尖崩缺），断口亮新面与旧氧化色对比 |
| 玉石 | 通透温润 → 微磨损：表面浅磨痕（软道），油脂光泽渐匀，微半透明保持 | 磨损 → 表面微裂：绺纹隐现、沁色自绺口缓渗（绺/沁为玉特有老化），棱角圆钝 | 裂纹/碎裂/缺角：绺裂加深贯通、磕缺崩口，断口呈玉质天然纹理与沁色层次 |
| 木质 | 新木纹理 → 自然包浆：漆层局部剥落（漆面 edge wear）、底层木纹渐显 | 包浆 → 色泽暗沉：木色转深（C8 赭石向）、干裂细纹、虫蛀小孔渐现 | 开裂/断裂/虫蛀：顺纹理开裂、虫蛀圆孔+蛀粉痕、断口纤维可见 |
| 瓷器 | 釉面光泽 → 微划痕：釉面软道细丝纹、口部微磕 | 划痕 → 釉面暗淡：釉光减退、缩釉棕眼处积尘、开片/冲线渐显 | 裂纹/碎裂/缺口：冲线贯通或炸纹放射（鸡爪纹）、口磕缺碴、碎裂断面釉胎分明 |
| 布/纸 | 崭新平整 → 微皱折：织物压痕/纸张折痕、轻微使用污渍 | 皱折 → 发黄变脆：纸本泛黄酸化（纸寿千年绢寿八百的缓退——裱画行话通称，宋·洪咨夔《题西岳降猎图》原句为"绢寿止五百年，纸寿千年"）、边缘卷边 | 撕裂/焦损/墨迹晕染：撕裂毛边、边缘焦黑碳化卷翘、水渍墨晕洇散 |

## 六、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 道具核心造型/轮廓在所有状态中可识别（L1 不变特征：造型轮廓+材质基底+主色全程锁定——L1 记号为本手册道具锚定层专用，与人物手册 L1 妆容层无关） |
| R2 | 状态变化须符合物理逻辑（受力/接触/环境逻辑决定损伤分布，禁跨材质错误如玉石生锈） |
| R3 | 必须使用四宫格（2×2）布局：左上正面图+右上侧面图+左下背面图+右下细节特写（单状态变体设定图专用；状态对比图按三节横向并排布局执行） |
| R4 | 必须指定「素灰纯色背景」，均匀柔光，无硬阴影 |
| R5 | 状态只作用于材质表面与结构损伤层，禁止借状态变体顺手改道具设计（改款/改纹样/改件数） |
| R6 | 状态须以可落图的变化词描述（材质变化+损伤形态+分布部位），禁只写状态名无视觉落点 |
| R7 | 状态对比图各状态须逐一对应关系清晰，角度/光线/背景完全一致，仅状态层差异 |
| R8 | 输出前复核五项：造型可识别/状态可读/无人物肢体/无佩戴使用态/无文字 |
| R9 | 必须携带统一负向词块与器物向锁质英文锚词（纯道具静物按全局前缀 X11「无人/纯器物场景豁免」条落场景档子集、清单以《art_scene》X15 为唯一权威；输出时成块附带、禁省略禁截断） |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 状态变化后道具不可识别（造型/轮廓/件名结构被状态吞没） |
| X2 | 违反物理逻辑的损伤（玉石生锈、瓷器弯折、纸本断裂如金属等） |
| X3 | 过度血腥/恐怖的损伤描绘（鲜红喷溅、大面积浸染、内脏断肢联想等） |
| X4 | 出现任何人物形象，包括全身、半身、局部（手、手指、手臂等肢体） |
| X5 | 道具处于被持有、握持、佩戴、使用中的状态 |
| X6 | 出现暗示人物存在的元素（如手持痕迹、佩戴视角、使用姿态） |
| X7 | 借状态变体改道具设计：换款/换形/换纹样/增减件数，导致与设定图断连 |
| X8 | 状态只写品名无视觉落点（缺材质变化/损伤形态/分布部位），AI 无法落图或乱渲 |
| X9 | 状态过度堆叠（全材质同时烂到极致、做旧贴图噪声淹没本体辨识），单状态只演单层变化 |
| X10 | 出图投喂未携带统一负向词块与器物向锁质英文锚词（本表 X 编号为手册局部编号、与全局前缀同名编号不同义——本表 X10 即全局前缀 X11 投喂条；同全局前缀X11「无人/纯器物场景豁免」条与《art_scene》X15 口径；漏投=整图柔焦雾化糊化+材质塑料化的直接成因，画面须锐利干净、焦点明确） |
| X11 | 材质肌理错误（抛光面长锈斑无划痕、新釉面起深冲线、木器烧焦如纸般卷曲等肌理与材质错位） |
