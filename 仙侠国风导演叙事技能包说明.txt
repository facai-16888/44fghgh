# 仙侠国风 · 导演叙事手法技能包

## 简介

本技能包为 **仙侠国风** 题材的燃向故事（少年问道、越阶逆天、宗门羁绊，承自热血王道叙事谱系）提供一套完整的导演叙事手法参考，涵盖从宏观叙事规划到微观分镜执行的全流程指导。视觉口径锁定 **工业级 3D 游戏 · 仙侠国风 · 半写实 CG 建模风格**（3D 写实渲染管线 + 国漫风格化面容，对标眷思量式影视级 3D 国漫资产，口径同本地全局前缀：禁 2D 插画平涂/写实摄影质感）；凡镜头语言、场景情绪与声音方向，均须落回本地《全局美学基础》（本地原稿：前缀提示词.txt）C1–C15 色盘、《国风3D约束》（本地原稿：导演规划.txt 与分镜表设计.txt）A–G 光影方案与 R/X 禁则的纪律之内执行，严禁风格漂移。

## 核心理念

- **燃点递进** — 燃感不是全程高能，而是自低谷受挫逐级攀升至破境爆发；落差越大，释压一刻越燃（按"按压—释放"的弹簧逻辑设计：蓄压须锯齿状回弹、踩在观众委屈阈值临界，爆发在期盼临界点提前半拍引爆；每 2–3 个压抑循环内须给一次解气级微型释放，防脱敏）
- **信念可视化** — 抽象的执念与道心要用具象的眼神、剑意、伤痕与招式外化，让观众"看见"决心（招式须携带名字、轨迹与情感驱动，战斗即成长的可视化，禁为打而打的特效堆叠）
- **以弱胜强** — 核心魅力来自"明知不可为而为之"的越阶一战：境界压制越悬殊、绝境越绝望、翻盘越燃（每一战必须带来突破或信念更替，而非单纯胜负；禁超人式不死身的无代价碾压）
- **伙伴共振** — 热血不是孤身问道，同门的信任、舍身护道与故人归来是最强催泪燃点（牺牲与回归须提前埋线，情绪落点在爆发之前完成蓄力，禁无铺垫的硬煽情）

## 技能文件说明

### 1. 叙事规划手法 (`director_planning_narrative.md`)

导演在 **叙事规划阶段** 使用的技法参考，定义仙侠国风燃向故事在主题立意、燃点节奏、场景情绪设计与声音方向上的整体规划方法（输出供《导演规划·国风3D约束》落地为情绪色盘绑定与 A–G 光影方案段落取定，禁"剧情对了、情绪色不对"）。

| 章节 | 内容概要 |
|---|---|
| 主题立意与热血内核 | 道心外化（信念可视化）、以弱胜强（越阶逆天）、伙伴羁绊（道友同门）、成长弧线（凡胎→问鼎的破境成长） |
| 叙事结构与燃点节奏 | 低谷→蓄势→爆发循环、三段式燃点递进（蓄力→临界→爆发三拍；仙侠落名"挫境-顿悟-破局"同义互参，两套命名指向同一拍序、勿作两种节奏）、情绪按压与释放的蓄力设计（锯齿状回弹、提前半拍引爆、微型释放防脱敏） |
| 分场景情绪设计 | 六大典型燃段设计（受挫低谷/奇遇顿悟/越阶小胜/绝境再压/舍身护道/逆天破境，逐段绑定八套情绪色盘并以 A–G 光影方案落段）、对抗升级叙事、空间战场化（宗门/洞府/秘境/云海各成战场） |
| 声音与音乐方向 | 鼓点递进与唢呐式爆发时机（高光一瞬即收）、沉默蓄力、燃曲破境爆发、呐喊与战吼留白（二者合并计数、择一为核） |
| 构图与景别叙事 | 低机位仰拍威压感/俯拍深渊绝境感/正邪对峙的对称构图、景别的力量表达（碾压/势均/智取三型各有构图） |
| 镜头运动与节奏 | 速度线（御剑拖尾，由画面内动素承担）、冲击升格（冲击瞬间缓速放大）、环绕升格（慢动作放大剑气轨迹）、爆发快推（对齐本地运镜词表并须满足本地「快节奏例外声明机制」三条件，禁甩镜急推） |

### 2. 分镜表叙事手法 (`director_storyboard_table_narrative.md`)

导演在 **分镜表制作阶段** 使用的技法参考，定义仙侠国风燃向在分镜表中的景别策略、运镜节奏、时长把控、斗法分镜设计与转场手法（成表字段对齐本地口径：每镜落定景别/机位角度/运镜/动作/色盘代号/光影方案代号/环境动态/时长八项，缺失即不合格）。

| 章节 | 内容概要 |
|---|---|
| 分镜表定位 | 分镜表作为节奏引擎核心工具的定位说明（未开拍即锁死画面纪律：180° 轴线、视线匹配、动作起止跨镜连戏，逐镜八项字段齐备） |
| 景别选择 | 力量感景别（低机位仰拍）、仰拍与俯拍的叙事功能（威压/绝境）、冲击特写（瞳孔映剑光=心神对焦，全片 3-4 次封顶） |
| 运镜节奏 | 静蓄动爆（快慢对比+呼吸点停顿）、速度感运镜（御剑/剑气拖尾）、环绕与跟拍（360° 环绕用于决定性时刻，全片 1-2 次封顶）、短距快推（武戏限定，挂接「快节奏例外声明机制」） |
| 时长把控 | 爆发前拉伸（预备动作略长于实际）、冲击瞬间压缩（1-1.5s 属剪辑层闪切，独立生成按平台最短档整段出再截取，禁强造 1s 短镜）、升格黄金时刻（4–8s 慢速时刻与 8s+ 决定性瞬间慎用；短镜只容单一动作） |
| 对抗镜头设计 | 攻防节奏（起势-压迫-转折-定胜负）、力量对比（重量感/速度感分型）、一击定胜负的镜头语言（预备-接触-反应三阶段视觉化） |
| 伙伴叙事 | 并肩御敌构图（双人同框互位）、信任传递镜头（背靠背/递剑/托付）、牺牲与回归（舍身护道与故人归来的情绪落点） |
| 台词与呐喊 | 道心宣言时机（爆发前半拍）、沉默的分量（蓄势静场）、战吼的克制使用（每幕至多一次核弹式高光，全片 2-3 次封顶） |
| 转场设计 | 冲击波转场/速度线过渡/黑屏蓄力/闪白爆发（对齐本地转场词表：硬切与叠化两级+场景空镜缓冲，禁花式转场；亮度级闪白分档取时长） |

## 使用方式

本技能包作为 ToonFlow 导演 AI 的仙侠国风叙事手法参考（Toonflow=开源一站式 AI 短剧/漫剧创作工作流，多 Agent 协作、决策层与执行层分工；本技能包即挂载于导演 Agent 的叙事手法 track。叙事手法 track 与本地《国风3D约束》风格 track 分工：本包定"为什么这样拍、怎么拍"，风格包定"拍成什么样"，两者于分镜表八项字段处合流），在故事创作流程中自动加载——先套《全局美学基础》锁定风格基线与禁则，再执行本包，指导：

1. **叙事规划** — 确定燃向内核（道心/逆天/羁绊）、燃点节奏曲线（按压-释放的蓄力标尺）、场景情绪（逐段绑定情绪色盘与 A–G 光影方案）与古乐爆发时机
2. **分镜表生成** — 根据叙事规划输出具体的景别、机位角度、运镜、时长、动作量级与转场方案（逐镜八项字段齐备）

两个文件分工明确、逐层递进，从"为什么这样拍"到"具体怎么拍"形成完整闭环（配合《全局美学基础》与《国风3D约束》，即组成"叙事→分镜→风格执行"的完整管线）。
