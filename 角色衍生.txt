# 人物 / 魔兽异兽衍生资产生成 · 约束手册

---

## 一、叠加原则

1. **面容不变** — 叠加后五官必须与底模完全一致，禁止面容偏移/换脸；面部描述词全程恒定（底图/参考图锁脸模，固定seed），妆容只着色不改形，痣/胎记等标志锚点不遮挡不消除
2. **姿态不变** — 保持底模自然站立姿态、重心与朝向，禁止任何姿态/动作/体态变化（姿态变化会牵动衣褶、发丝与比例变形，破坏叠加参照一致性）
3. **逐层可控** — 每层独立成段描述、互不污染，便于按层替换与跨层复用（换装不换妆、换发饰不动发型，层间不串词）
4. **风格统一** — 所有服化元素服从同一美学体系：3D写实渲染管线 + 国漫风格化面容（半写实CG，眷思量式锚定，面容按国漫美化基准执行（基准底线与禁西化口径见《art_character》§二）——上限对标斗罗/斗破剧场版级美型男主；底模面容的利落美型感在叠加时只许精修线条、禁以妆容描线回归西化立体度），次世代建模/PBR物理材质/电影级光影与中国传统色盘贯穿各层
5. **质感不降** — 叠加后质感标准不低于底模：PBR材质渲染、细节密度对标影视级3D国漫资产，妆面不压肤质、皮肤保留细微微纹理呼吸感（禁过度磨皮哑光娃娃肌/冷调漂白/苍灰惨白/过曝压平纹理）、布料软垂细褶有垂坠厚度（禁挺括浆硬制服感）、金属玉石各具真实反射，禁止塑料蜡像感、贴图模糊与全画面柔焦雾化磨糊（浅景深焦外虚化不在禁列）；发丝保持单根至发梢自然收尖羽化不糊片不粘连，禁成束成片糊块或发梢融合钝化；叠加投喂须随prompt携带《art_character》§八统一负向词块与锁质英文锚词（同全局前缀X11/X12口径——含 X12 眼神锁神锚词），防模型默认美颜/柔焦bias把妆面肤质与布料细节压平
6. **纯服化范畴** — 仅叠加 L1 妆容/L2 发型/L3 中衣/L4 主服/L5 配饰五层，禁止引入道具、场景、环境、动作（各属独立资产类型，混入即违例）

## 二、叠加层级

| 层级 | 内容 | 说明 |
|---|---|---|
| L0 | 底模 | 基础形象底模（人物基础形象生成产出），跨镜头锁定，不修改、不重绘 |
| L1 | 妆容（决策层） | 先分析用户线索，再决策「基础妆 / 轻妆 / 正式妆」强度，并落妆造风格矩阵（见第三节） |
| L2 | 发型造型 | 发髻/束发/编发/马尾等（形制考据词）+ 发饰（位置 + 材质 + 工艺） |
| L3 | 中衣/内搭 | 替换白色基础中衣（交领中衣、素色内衬，襟口与底模衔接不穿模） |
| L4 | 外衣/主服 | 古风华服/礼服/常服/嫁衣等，主色锁定中国传统色盘编号，纹样刺绣按服饰等级分级 |
| L5 | 配饰 | 头饰/耳饰/项饰/腰饰/手饰，材质分级金银 + 珠玉 + 流苏 |

> **范畴边界**：人物衍生资产仅包含 L0-L5 层级（服化妆造），不包含道具（伞/剑/扇/书/灯笼等手持物）、场景环境（室内/室外/天气等）、姿态动作（行走/回眸/举手等）。这些属于其他资产类型的范畴。L1 妆容仅作用于五官着色与肤质表现，不改变脸型骨相与标志锚点。（非人角色的兽形衍生口径见 §十一，兽具层 L1-L5 与人物服化层 L1-L5 两套分开、不互染。）
> **服饰状态例外**：血迹/破损/战损/湿透/泥污等"戏用状态"属 L4 主服的状态叠加档（仅作用于衣物，不触及妆容发饰与底模），由剧本原文状态词触发（如"黑衣染血"）、按场次单独产出（回查原文状态词与落色：血迹陈旧氧化向 C3/C8、禁鲜红喷溅），禁混入洁净服化四视图——洁净装=资产主线，战损状态=按场调用档，两套分开不互染。

## 三、妆容约束（L1）

### 底模到衍生妆造策略（关键）

> 角色底模虽为素颜，但衍生资产默认进入妆造流程。系统应根据用户提供的线索分析妆造需求，并在基础妆、轻妆、正式妆之间决策强度，而不是保持素颜。妆容强度与风格映射中国传统妆容四期谱系（汉素雅/唐秾丽/宋清雅/明精致），决策后按3D写实渲染口径落词。

### L1 线索分析与妆容决策

| 步骤 | 处理内容 | 决策结果 |
|---|---|---|
| S1 | 提取用户线索：面部状态词、情绪词、强度词，并识别情境标签（场合类型） | 形成妆容需求摘要 + 情境档 |
| S2 | 过滤非妆容线索：道具/场景/动作/姿态词不作为上妆依据 | 防止误判（仅作情境标签，不抬升强度） |
| S3 | 匹配妆容风格矩阵并给出强度档 | 基础妆 / 轻妆 / 正式妆 |
| S4 | 生成最终 L1 提示词，只输出结论，不输出分析过程 | 妆容结论句 = 风格 + 强度档 + 眉/眼/颊/唇部位词 + 底肤词 |

### 线索到妆容映射（执行口径）

| 线索类型 | 典型线索 | L1 决策 |
|---|---|---|
| 无明显面部强调线索 | 仅服饰/发型变化，未强调情绪与状态 | 基础妆（清雅素妆，宋式素妆基线：远山黛淡扫、浅朱樱唇、薄施粉檀若有似无） |
| 轻微面部线索 | 轻柔、含笑、睫毛轻颤、气色微提 | 轻妆（极淡，介于素妆与桃花妆之间的轻晕） |
| 明确日常线索 | 日常、外出、休闲 | 基础妆（自然清透，妆感隐于肤） |
| 明确正式仪式线索 | 大婚、典礼、重要场合 | 正式妆（精致华贵，按场合落贵气妆/盛妆矩阵） |

> 判定原则：所有衍生资产都要有妆造；先看面部线索决定强度与风格，道具、场景、姿态变化不得单独抬高妆容强度；同角色妆容气质跨场景沿用同一基线，禁现代浓妆/网红整容脸混入古风妆面。

## 十一、魔兽/异兽/灵兽类 · 非人角色衍生扩展

> 本章为 §一-§十 人类角色服化衍生口径的**非人角色扩展**，用于魔兽/异兽/灵兽/神兽等兽形生物的衍生叠加（兽甲/鞍具/契约纹饰/披挂/铭刻）；人类 L1-L5 服化层（妆容/发型/中衣/主服/配饰）不适用于兽形，兽形按本章 L1-L5 兽具层执行，两套分开、不互染；本章未尽事项一律沿用本手册通用纪律（逐层可控、风格统一、质感不降、四视图一致、统一负向词块与锁质锚词投喂），以下仅列兽形衍生专属差异项。

### 叠加原则（兽形）

1. **骨相不变** — 叠加后兽形骨相必须与底模（《art_character》§十一 兽形底模）完全一致，禁止换头换种/骨相漂移；头骨/瞳形/毛羽鳞甲/体型比例描述词全程恒定（底图/参考图锁兽形，固定seed），兽具只加不换形
2. **姿态不变** — 保持底模自然站立（四足平行微分、翼尾自然收拢），禁止任何姿态/动作变化（扑咬/振翅/奔袭会牵动兽甲贴合、鬃毛走向与比例变形，破坏叠加参照一致性）
3. **逐层可控** — 每层独立成段描述、互不污染，便于按层替换与跨层复用（换甲不换兽、换鞍不动甲，层间不串词）
4. **风格统一** — 所有兽具服从同一美学体系：3D写实渲染管线 + 国漫玄幻兽形（半写实CG，眷思量式锚定，《art_character》§十一 兽形基准底线为形制下限），次世代建模/PBR物理材质/电影级光影与中国传统色盘贯穿各层；兽具形制走东方玄幻谱系，禁西式骑士鞍/蒸汽金属件/现代马具与西式奇幻套用
5. **质感不降** — 叠加后质感标准不低于底模：皮革/金属/角质/织物四类材质光响应各异可辨（皮革哑光起皱有使用感、金属旧化微划痕、角质半透、织物软垂），禁塑料蜡像感、贴图糊块与全画面柔焦雾化磨糊；兽甲边缘与兽体衔接不穿模不浮空；叠加投喂须随prompt携带《art_character》§十一 统一负向词块与锁质英文锚词（同全局前缀X11/X12口径——含 X12 锁神锚词，兽形版），禁省略禁截断
6. **不遮识别锚点** — 兽甲/披挂/铭刻不得遮挡血脉标记（契纹/异纹/旧疤）、兽冠/角与断牙缺耳的识别锚点，原位清晰可见、跨镜位置恒定（对齐《art_character》§十一 R28）
7. **纯兽具范畴** — 仅叠加 L1 兽甲/L2 鞍具/L3 契约封印装具/L4 披挂纹饰/L5 铭刻挂饰五层，禁止引入人物服化层、道具、场景、环境、动作（各属独立资产类型，混入即违例）；兽体自身外观（毛羽鳞甲/兽冠/血脉标记）属底模、不在本章改动范围
